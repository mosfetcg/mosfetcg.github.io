## 光学单位
研究光的性质和测量值有助于建模和理解渲染。  

光子(Photons)
```ruby
q   # 能量，J
p   # 位置
dir # 传播方向
λ   # 波长 —— 两个相邻的峰之间的物理距离，nm
c   # 速度

h = 6.63 * 10^-34 J #Plank’s Constant
q = hc/λ
```

> 球立体角(圆锥形)`σ`的弧度制`球面度(steradians)`，是锥体投影球表面的那块面积。  

```ruby
Q   # 光谱能量(spectral energy)
= dq/dλ  # 波长差分能量和。dλ通常物理上取1nm测得视为理论Q。这是一种常见约定。
```
因此预测时，Δq = QΔλ。  

与时间、面积、立体角关联后，定义同理。  
```ruby
    # 功率单位瓦W = J/s
Φ   # 光谱功率(spectral power) ，W/nm
= dQ/dt  # 时间差分能量

Ei  # 入辐照度(irradiance)，J/m^2/s/nm
Eo  # 出辐照度(radiant exitance)
= dΦ/dA  # 面积差分功率

Li  # 入辐射度(field radiance)
Lo  # 出辐射度(surface radiance)
= dE / dωcosθ   # 方向差分辐照度
                # 无需在意余弦矫正的证明
```

## 一般方法求解E
```ruby
Ei = ∫ω|dEi = Li(ω)cosθ dω
```
我们先不使用蒙特卡洛。这个积分可以直接用普通黎曼求解。可以把半球切成dω = 2Pi/N份，并且你知道Li(ωi)。  
或者在球系中使用等效的du = sinPdPdA去求和(P极角)。  

## BRDF
```ruby
ρ = Lo/Ei
```
反射辐射度之于特定常量接受面积能量(辐照度)。该定义与实验室测量极其相关。  

一束激光沿着固定方向砸在桌面上的一块特定面积上，这块面积接收到的总功率密度就是Ei。此时，这个面积上的能量是常量、固定的。  
这块面积把接收到的光能铺天盖地地散射到了上方的整个天空中。  

接下来，改变激光方向，Ei会改变。死死根据这个等式，继续测得所有数据。我们通过函数ρ(i,o)获得数据。  
我们可以得到该材质的属性。

#### 传输方程
*方向半球反射率(501)*  
根据BRDF，我们定义`方向半球反射率(directional hemispherical reflectance)`表示特定入射在所有反射方向上的总反射率。  
`R(vi) = power_in_all_vo / power_in_a_vi`；由于能量守恒，该量介于单位1之间。  
```ruby
R(vi) = Ho/Hi
Lo = Hiρ = Φi/ΔA
Lo = ΔHo/(dvo*cosθvo) # definition

=> Hiρ = ΔHo/(dvo*cosθvo)
   ΔHo/Hi = ρ dvo cosθvo
R(vi)=∫半球出射vo| ρ(i,o)cosθvo dvo    # 487，略

R(vi)=∫半球出射vo| Ccosθvo dvo = PiC   # Lambertian 略，简化为二重积分(见上)
```
朗伯BRDF描述了一种理想漫射表面，这种表面对于任何角度使用常数项`ρ(i,o) = C`。  
若理想朗伯存在`R = 1`的完全反射，因此得到假设常数实际为`ρ = 1/Pi`。若`R(i) = self.albedo`，则`ρ = self.albedo / Pi`；立体角再次引入了PI常数。  
```ruby
ρ = Lo /(Li cosθvi dvi)
ΔLo = ρLicosθvidvi
# ↓
```

**传输方程(Transport Equation)**  
```ruby
Lo(vo)=∫半球入射vi| ρ(i,o) Li(vi)cosθvi dvi
                   #BRDF      # 每条半球入射光线的矫正
```
这通常称为计算机图形中的`渲染方程(1986)(rendering equation)`。  

另一种方程(18.2)形式采样空间中一块面积，而不是立体角(转换)。  
```ruby
dvi = (cosθarea/r²)dA # r距离
#===================== 
 --.dA-- 
 r/  n\θarea
 /  n\
-.dvi-cosθ1 #local
```
```ruby
Lo(p,vo)=∫area| ρ(i,o)Licosθ1 (cosθarea/r²)dA
V(p_local, p_area) = 1/0
```
当采样面积被遮挡时(如采样光源面积)，需要增加阴影光线判定函数`V(ray)`到积分中。检查其贡献是否为`0`。  

**光度/光子测量学(`photometry`)**  
对于每个光谱辐射量，都有一个相关的**光度测量量**，用于测量该量有多少对人类观察者有用。

#### 23. 全局光照
如前所述，`路径追踪(path tracing)`通常是全局光照问题的直接解决参考文献之一。  
我们先解释渲染方程的具体求解方法以及进一步明确利用辐射度的正确性。  

```ruby
Lo(vo)=∫半球入射vi| ρ(i,o) Li(vi)cosθvi dvi  # 渲染方程
```
我们想要的是表面朝着给定方向的出射辐射度，例如正好反射到眼睛里的光线。  
那么这个值最后应该是多少？我们用估值器计算右侧积分的函数。建议`/pdvi`的概率与BRDF相同。  
```ruby
~= 1/N[Σ(i=1..N)fvi/pvi]
```
检查Li(vi)项，这些光线本身的辐射度从哪里来呢？别忘了我们从递归或循环中散射光线，因此它最终是可以被评估的，并最终来自于任意光源！当我们击中灯具，我们就结束了。该方法假设灯的反射率为零，否则我们将继续递归。  
对于简单情况，我们假定使用RGB颜色作为辐射度的直接映射。  

朗伯的BRDF`ρ = self.albedo / Pi`是一个均匀分配后的常数，我们可以使用`p(vi) = cosθvi / Pi`余弦密度(619,请推导)。这给出估值器的简单表达式：  
```ruby
+= self.albedo Li(vi)
```

**更完整的渲染方程(full transport equation)**  
(23.2)包含一个发光项，称为emmit。明确此形式的主要原因在于编程模型，发光项仅在光源提供，如天空和灯具返回其的固定值(并结束任何进一步的追踪)以提供给其他表面接受的`Li`，当然大多表面不会增加自发光量。  
```ruby
Lo(vo) = ∫ + emmit(vo)
```

**高级**  
只是轻易计算默认的渲染方程很容易导致弱照明场景的错误，需要采用其他策略进行优化。请见外部(已转移)。  

**准确的直接照明(23.3)**  
比起应用传统的直接光照模型，使用部分路径追踪技术可以捕获更基于物理的直接光照结果。  
通过求解面积形式的渲染方程，并对光源面积采样，可以产生漂亮的阴影和直接照明结果。  

样本、描述样本的密度必须围绕灯具上的随机点展开。可以均匀随机选择灯具表面上一点，蒙特卡洛密度为`p = 1 / A`。
