## 核心概念
图形学指**用程序来创建和修改图像**(的方法)。特别是数学和算法。  

#### 理解程序和管道
图形程序员编写两部分程序，**图形和主机程序**。图形端主要负责执行渲染命令开始之后的各种效果，主机端是任意可能的逻辑，但会最终调用渲染命令。  
因此，读者需要知道硬件环境和API以便利用硬件和现有算法。  
在这个体系中，称为**图形管道**，实现了一套特定的渲染算法(光栅图形)的**流程**，将几种简单的图元渲染成图像。图形端可以控制渲染中的各种效果。  

您当然可以只是用CPU编写图形程序，并且不了解"光栅"，其原理是图形学学习的一部分。因为如果您的目的是路径追踪等其他渲染算法的方面，则学习路径大不相同，实际算法决定了如何决定使用这些资源。  

编写图形程序的几条建议是：性能方面，多关注内存访问瓶颈。  
结构方面，为几何实体(向量、间隔、坐标系等)、图形(颜色、图片等)实体创建良好的类，干净、高效。  

`▼`OpenGL以及图形管道可能是最无聊，具有最多细节的部分。我们在最后一节讨论此"流程"。

#### 理解渲染 
在我看来，尽管渲染的标准含义是场景描述->图像的全部程序。涉及各种算法，我只认为"着色"是主要部分，其影响效果和质量最大。  

**场景描述**：几何体的可理解形式。通常认为"交点，法线"等结果以及可知的"对象遮挡顺序"才是起点。之前的部分不属于渲染问题，之后属于渲染的输入。

确定几何体到渲染输入的格式的问题叫做"表面能见度测定"。  

**着色**：如前所述，我认为组成了渲染的核心要素。包括极丰富的光照问题。  

**函数顺序**：有一个抽象的分类或者判断，基于图元对象集互相影响图像像素集的关系，有两种处理可能，要么为一个像素考虑场景如何决定该像素，要么为一个对象决定影响哪些像素。这称为图像顺序或对象顺序。两者涉及的算法机制也大有不同，导致了两大主流。  

**视角**：包含特定如何从人类可理解的视角观察场景的考虑，例如相机、视口、透视(perspective)等。  

#### 理解像素
像素之所以重要，是因为结果都是像素。  
由于像素的结果极其重要。我们可以提升颜色相关的理论来实现更好的图形效果。  

合并：通常，两层像素是"实"的。某些效果通过对两层像素的处理完成。这就是混合。  
在混合技术中，最简单的是调整两者的比例，例如在RGBA通道中，两者根据A进行线性混合。  
意识到该技术之所以重要，是因为可以产生一些其他非直觉(单层自身产生)的艺术视觉效果。  

类似的问题可以推广到如何处理不同图像之间的抽象问题，注意，无论在生产单个图像都可以存在。  

#### 理解模型
模型可以是数学的，三角化的。伴随大量算法。

简单的模型之间还可以互相构造(如CSG -constructive solid geometry)。  
任何能够计算与三维直线交点的几何图元，都可以无缝地集成到光线追踪器中。图元组(构成一个模型)中，可以求解多个交点，然后维护间隔再使用布尔运算以实现CSG。

## 理解视角
#### 相机
针孔相机成像是计算机图形学和摄影中最基础的相机模型。  
其中，经过孔洞的光线会颠倒的打在孔后面的传感器或底片平面上。孔和整个封闭的盒子保证了无其他方向光线的干扰。  
可视区域FOV(Field of view)就是孔前面连接传感器面的对称区域。  

透镜（Lens）：  
焦点 (Focal Point)：一串平行光穿过凸透镜折射后，全部向内汇聚交于一点，该点即为焦点。  
焦距 (Focal Length)：从透镜中心到焦点的物理距离。  
对于单片硬质透镜的物理焦距是固定不变的。  
通过透镜的三条具有特殊数学规律的几何光线(平行光折射后穿过焦点再穿过成像点，物体点到透镜中心点再到成像点不折射，物体到外焦点再折射后会平行到达成像点 )，可以定位出该对象的成像点。如果你把透镜相机的图像传感器恰好放在这个交点所在的垂直平面上，就不会模糊（对焦成功）。

另外，只有该物体所在的平面附近的区域是清晰的。(带有容差)可以看清的纵深范围，在摄影中就被称为景深（Depth of Field, 简称 DoF）。  
镜片本来就拍不出所有地方都清楚的图像。  

视野 (FOV) 的数学决定：在传感器尺寸固定的前提下，焦距决定了视角FOV。焦距越短（传感器离镜片越近），外侧的 FOV 视角就越宽广（广角）；焦距越长，FOV 视角就越窄（长焦）。

传感器在快门打开的曝光期间收集辐照度，现代相机在传感器前覆盖了一层拜尔滤镜 (Bayer Filter)，相机通过去马赛克 (Demosaicing) 算法，根据周围邻近像素的颜色进行数学插值和猜测，让每一个像素点都获得完整的 RGB 颜色，还原出彩色世界。  

请注意，透镜相机是为了解决小孔相机的光线质量问题。我们可以使用更简单的模型去模拟。  

#### 视口
在图形学中，我们可以生产完全清晰的图像。  

选择一个`视点(eye point)`前方产生`视口(viewport)`，视点到视口中心的连线垂直于视口平面，然后连线发送光线。理论上，光线应该命中于视口上并成像。实践中，应该屏蔽掉后方的对象，因为光线在视点发出仍然可能命中此类物体。  
另外，焦距只是被用于控制其垂直距离，并且与FOV角度一起控制视口垂直大小。  

为了方便，可以设置相机的仿射矩阵，然后在其本地Z轴计算放置视口。并将光线转回世界空间。同时使得计算和控制简化。  
其他控制方式则来源于图形学的一般约定，例如lookAt，up方向，偏航控制等，根据习惯使用。

## 着色模型
标准模型，至于其他方式请见外文。  

#### 约定
```ruby
l  # 光线    表面指向光源(光源点减去交点)的单位向量
e  # 视角线  表面指向眼睛的单位向量
m  # l,e的中间方向
```

#### 朗伯(Lambertian)着色
```ruby
Col1 = kd * I * max(0, n·l)
```
其中，Kd为材质对RGB三种光的反射率，I包含三种光的强度。  
这认为直射表面的反射光最强，否则衰减至0。  

#### 布林-冯(Blinn-Phong)着色
这认为表面具有光泽度，且在光线、视角与N对称时，将称为所谓的`镜面高光反射(specular reflections)`反射到眼睛中。  
由于n、l固定，唯一变量只有e角度，要么会看到强烈的反光，要么就衰减。  
通常该模型与朗伯一起使用。  

对齐度是通过l,v的中间向量和n的偏差探测的。因为其l,v长度相等，l+v位于角平分线上。  
```ruby
m = norm(v+l)
Col2 = ks * I * max(0, n·m)^p
```
其中，Ks为材质系数。  

#### 环境(ambient)
该项模仿环境中充盈的余光，要么是远处的环境光，要么是对象的间接光。  
当然，我认为宇宙中，地球的背面就不存在什么环境光，除非是一个房间里，或者大地上(天空充当)。  
```ruby
Col3  = ka * Ia
```
其中，Ka为材质系数。注意Ia的强度可能随空间变化。  


#### 小结
多光源：对所有光源求和。  

上述模型大致上遵循一些物理模型。注意Col1,Col2，I指的是同一个灯源，其强度应该随着空间距离衰减。  
这几个模型可以组合实现不同的材料，例如具有光源高光的瓷砖漫反射表面，纯漫反射，纯镜面照明。一般而言，高光都是光源颜色。

#### 透射
现实中有的物质同时发生反射和折射(无论是看它还是返回)，从而导致一种特殊的表面外观。  

###### 斯涅尔定理
当光线从折射率为n的介质传播到折射率为nt的介质时，部分光会被透射，并且会发生弯曲。其角度与介质的折射率(refractive index)和入射角度决定：nsinA = ntSinT。  
```cpp
vec3 refracted(vec3 v, vec3 n, float ratio) {
  return ratio * (v - dot(v, n) * n) - sqrt(1.0 - pow(ratio, 2.0) * (1.0 - pow(dot(v, n), 2.0))) * n;
}
vec3 reflected(vec3 v, vec3 n) {
  return v - 2.0 * dot(v, n) * n;
}
// 可从内置函数获取折射角度
reflect(v,n);
refract(v,n,from/to);
```
每种折射率都是从**真空**进入材料时的弯曲(bend)程度测量的。率的翻译基本是一个错误，它仅是一个常数值。由于测量时真空的相对性和率一起会产生误解，实际上每个只是该材料的已知值。  
当透明材料嵌入到不同的透明材料中时，则可以用相对折射率来描述折射：物体材料的折射率除以周围材料的折射率`a/b`。  
例如，如果要渲染水下的玻璃球，则有效折射率为`玻璃/水 = 1.5/1.333 = 1.125`。常见材料的折射率非常容易找到。  

###### 全内反射
如果角度不存在，那么光线只会被反射。由于通常发生在较大折射率介质的内部，所以被称为`完全内反射(total internal reflection)`。  
这就是为什么有时当你在水下时，水与空气的边界就像一面完美的镜子——如果你在水下向上看，你可以看到水面以上的东西，但当你靠近水面并向侧面看时，水面看起来像一面镜子。  

###### 菲涅尔效应(Fresnel Effects)
除此之外，该材料的视觉效果——反射、折射之比，随着入射角度变化。Schlick近似：  

水平观察湖面时，反射会更多。垂直观察湖面时，折射比较多。  
```cpp
float r0 = (from - to) / (from + to);
r0 *= r0;
return r0 + (1.0 - r0) * pow((1.0 - cos_v), 5.0);
```
```cpp
/* 简化版本，注意使"v"朝外 */
fresnel = pow(1.0 - dot(v, n), 5.0);
```

###### 滤光
有些玻璃比起绿色过滤更多蓝色和红色，呈绿色。  

###### 杂质衰减
强度根据`比尔法(Beer’s Law)`衰减。其中s是距离，I0为初始强度，a是每单位衰减RGB系数。  
```ruby
I(s) = I(0) * a^s
```

#### 焦散模糊
设计一个对焦平面距离s，让视口光线rd穿过该平面到达P1。  
在视点作一个小圆镜头随机采样，再连接此点。

## 光线行进
`光线行进(Ray marching)`使用场景距离场最小步进检测对象命中，因为计算所有对象的最小距离，如果光线位于该对象正前方，那就能命中它。如果只能被错过，则SDF越来越大，光线将错过所有物体。  

`▼`理解其模型定义以及交点计算的微妙区别。其他方面几乎没什么不同，不过多了一种可在步进过程中做一些事情的可能性。这使得免费的软阴影，体积渲染，AO成为可能。  
```cpp
float marching( in vec3 ro, in vec3 rd) {
  float t = 0.0;
  for (int i = 0; i < 100; ++i) {
    vec3 p = ro + t * rd;
    float dmin = sdf(p);

    if (dmin < .01) return t;
    if (t > 100.) break;
    t += dmin;
  }
  return -1.0;
}
```
