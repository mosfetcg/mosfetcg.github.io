在图形学中，`参与介质(participating media)`指光线穿过时会与其发生相互作用的体积物质。  

# 作用

### 吸收
```ruby
dL(p,ω) = -σa(p)L(p,ω)ds
```
σa(p)每单位距离吸收密度。  
如果介质中的微粒较稀疏，只有一部分被吸收，整体看起来比较半透明、轻薄。高密度，绝大部分进入烟云的光线在极短的距离内就被完全吸收了，导致光线无法穿透。

### 透射率
沿着w前进总距离s会产生什么变化？
```ruby
dL(p,ω)/L(p,ω) = -σa(p)ds 
=>  ∫[1/L(p,ω)]dL(p,ω) = ∫-σa(p)ds              # 对两侧同时积分，左侧看作1/v函数替换
logL(p+sω,ω)-logL(p,ω) = -∫0..s|σa(p+s'ω,ω)ds'  # 沿着w前进总距离s
L(p+sω,ω)=e^(-∫0..s|σa(p+s'ω,ω)ds')L(p,ω)       # ln很难看，两边同时取以 e为底的指数（对数相减相当于真数相除，
L(p+sω,ω) = T(s)L(p,ω)
```
对比衰减值，该T(s) = (1/e)^∫s称为**透射率(transmittance)**。类似于一种不透明度系数。积分为0时，完全透光。积分项通常称为光学厚度t(s)，如果σa是常数，则可以简化积分为σas，这通常称为比尔法T(s)=(1/e)^σas。  

### 散射
类似于吸收，部分粒子会将能量散射出去，σs(p)每单位距离散射密度。  
其反射率可以近似由散射密度除以总密度代表能量描述。如果散射密度等于0(出能量为0)，全部发生吸收，则反射率为0，这是“死黑、焦黑”的浓烟。如果吸收密度为0，光线只是换个方向，例如白云、大雾。  
```ruby
σs(p)
ρ = σs/σs+σa
```

### 发光
粒子会发光。并增加该方向的辐射度。  
```ruby
dL(p,ω) = σa(p)Le(p,ω)ds
```
这个吸收项，在热力学中，这被称为基尔霍夫热辐射定律，善吸收者必善发射：一个微粒对某种波长光线的吸收能力越强它在受热或激发时，向外发射该波长光线的效率也就越高。  

### 内散射
该粒子被周围光线照亮并反弹到ω方向的辐射度增益。  
散射密度越高，云朵反而越白、细节越丰富。  
```ruby
S(p,ω) = σs(p)∫S²|p(ω‘->ω)L(p,ω')dω'
```

这个有趣的分布项在这里称为Phase(而不是BRDF)，其积分为1。来自天文学和气象学（最初用来描述行星偏振和月相变化，故称“相”函数）  
θ为相角，偏转夹角。极坐标图中，0度表示直线前进。
```ruby
cosθ = ω·ω'
# 各向同性
p(cosθ) = 1/4PI
# 瑞利散射。适用于微粒尺寸远小于光波长的情况
p(cosθ) = 0.75(1+cos²θ), σs反比1/λ^4
# 米氏散射。微粒尺寸与光波长接近或大于光波长。如云层中的水滴、大雾、烟尘。见图片。零度有一个巨大散射趋势。其他方向具有波动性。
```

# HG相函数
Mie散射公式带有复杂的锯齿波动，难以进行采样计算。HG是经验拟合公式，是图形学最常用、最伟大的体体积相函数模型。  
只要改变g值，整个相函数的极系分布形状就会发生剧烈的改变。g>0向前，g<0向后。其CDF有解析逆，非常容易使用。

# 直接照明
```ruby
Sd(p',ω) = σs(p')∫S²|p(ω‘->ω)Ld(p',ω')dω'
```
计算某个粒子的内散射的直接光源增益时，与表面无异，建议使用相函数和直接光采样的MIS。  
Sd中的积分用蒙特卡洛抽样，需要知道采样方向出来的PDF，如果没有MIS，用相函数的值就可以了，此时两个会被约掉。  

计算阴影射线很昂贵，它不会被一个粒子挡住，而是需要计算**光源和给定点之间路径的透射率**是否为0。因此就是计算前面的透射率。  

# 间接照明
在一个点,我们不仅需要计算直接光照需要的透射率,也计算之前一条路径的透射率衰减到beta值中。  
何时决定一个粒子距离可能是一个问题。  

# 单次散射(single scattering)
单次散射是体积路径追踪中最简单、最干净的一种情况。  
光线从太阳发射出来，穿过树面和雾气。在半路上，它只撞击了一个雾气微粒（发生了一次散射），然后就笔直、直接地飞进了相机的镜头。  
这种一束体积光，一束阴影块的视觉效果，是因为透射率高和低，并且直接光照非常强造成的。计算上也可以完全无视间接部分。

# 体积渲染方程
```ruby
L(p,ω) = ∫0..INF|T(p')S(p',ω)ds' # 见间接照明部分
```
如何采样ds'？  

# 采样模式
第一种最基础的解法是有限长度的均匀概率分布。认为光线在区间内的任何一个位置撞击粒子的概率全都是一模一样均等的p = 1/tmax。因此，CDF = ξtmax。  
它完全无视了比尔定律，光线刚进入烟雾时（靠近 0 的地方）最容易撞到粒子；越往深处走，光线早就被前面吸干了，能走到深处的概率极低。但这种线性采样依然在深处和浅处分配了一模一样的采样点。  
另外，方差很大。
