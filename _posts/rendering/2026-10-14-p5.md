# 设置
#### JS
```js
let graph_width = 500.0;
let graph_ratio = 16 / 9.0;
let _shader;

function preload() {
  _shader = loadShader('shader.vert', 'shader.frag');
}

function setup() {
  createCanvas(graph_width, graph_width / graph_ratio, WEBGL);
  shader(_shader);
}

function draw() {
  _shader.setUniform('u_time', frameCount / 60);
  _shader.setUniform('u_res', [width, height]);
  rect(0, 0, width, height);
}
```
计算返回值在`main()`的末尾给出，我们必须给`gl_Position`以及`gl_FragColor`赋值。  
#### 顶点示例
尽管顶点着色器起着重要的作用，它通常只负责确保我们创建的几何体正确显示。许多项目中重复使用相同的顶点着色器。  
这个缩放是为了修正草图的位置。  
```c
#version 300 es
in vec3 aPosition;
in vec2 aTexCoord;
out vec2 tex;

void main() {
  tex = aTexCoord;
    
  vec4 pos = vec4(aPosition, 1.0);
  pos.xy = pos.xy * 2.0 - 1.0;
  gl_Position = pos;
}
```

##### 输出作为纹理
缓冲器输出可作为纹理访问，此方法可访问上一帧的图像或数据。  
草图允许创建多个上下文渲染器。副渲染器是诸如`p5.Graphics`的封装(绘制到屏幕外)，其绘制表面称为草图图形缓冲器。  
单个渲染器可以加载草图帧缓冲器，此表面也类似于渲染器，但与其父类共享上下文。指令必须放置在`begin()/end()`之间，其目的在于加速需要纹理访问的应用。  
```
createCanvas()    --> p5.Renderer  --> createFramebuffer() -> p5.Framebuffer
createGraphics()  --> p5.Graphics  --> createFramebuffer() -> p5.Framebuffer
                graphics buffer ↑
```
##### 默认输入参考、处理3D顶点和矩阵
下面是所有可用主要属性参考。通常渲染引擎会提供光栅化的标准矩阵。  
可以使用草图的光栅化管道制作光栅化渲染程序。  
```c
in vec3 aPosition;       // 包含此顶点位置信息
in vec2 aTexCoord;       // 片像素位置的标准坐标[0..1] 使用它来访问屏幕上的每个像素
                         // out vec2 tex;
in vec3 aNormal;         // 几何体预处理顶点标准向量
in vec4 aDirection;
------------------------
// 模型矩阵定义对象位置/旋转/缩放
// 视矩阵定义相机属性，例如焦距和相机位置
uniform mat4 uModelViewMatrix;          // 已经合并的模型矩阵和视矩阵
  uModelMatrix * vec4(aPosition, 1.0)     // 将对象的局部位置移动到世界位置
  uModelViewMatrix * vec4(aPosition, 1.0) // 移动到相机位置
uniform mat4 uProjectionMatrix;
// uniform vec4 uViewPort;
  // 投影顺序为               projection * view * model * position
  //                        由于模型和视图已合并，只需  projection * modelView * position
  gl_Position = uProjectionMatrix * uModelViewMatrix * positionVec4;
```
```c
#version 300 es
in vec3 aPosition;
in vec2 aTexCoord;
in vec3 aNormal;
out vec2 tex;
out vec3 n;
out vec3 p;

uniform mat4 uProjectionMatrix;
uniform mat4 uModelViewMatrix;

void main() {
  tex = aTexCoord;
  n = aNormal;
  p = aPosition;

  vec4 pos = vec4(aPosition, 1.0);
  gl_Position = uProjectionMatrix * uModelViewMatrix * pos;
}
```
