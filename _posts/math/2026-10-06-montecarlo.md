```ruby
E(x) = ∫S|xp(x)dx                    # x~p理论期望值
V(x) = E([x-E(x)]²) = E(x²)-[E(x)]²
```
基于大数定律可以通过无限实验样本接近理论期望，本文称为估值器(estimator)。  
由于整体接近均值，样本方差趋于稳定。  
```ruby
EST(x) = Σx / n ~= E(x)
```
上述x是一个通用形式。在函数中，x和f(x)是映射的，两者都可以认为是随机变量，取决于E，或者估值器想要研究哪个对象。  

给定函数f，其积分为：
```ruby
# 5-45
I = ∫s|f()du = [f()/p()] * p() du
             = E(f/p)
             ~= Σf/p /n
```
通过估值f/p，可以得到f的积分数值解。越接近期望，积分就越准确。  

注意p完全是我们引入的东西，在统计中，如果f/p方差较小(定值，出现的数值较近"均值")，理想状态下常数f/p的方差为0，如果我们选择的P形状与f相似(观察分式)，那么估值器就会更快收敛准确结果。  
智能的选择采样分布称为重要性采样，另外，在图形学中，证明分层采样也可以降低方差。
