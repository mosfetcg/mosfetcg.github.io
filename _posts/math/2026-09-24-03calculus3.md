## 8. 多变量微积分
本节应该是所有数学内容中第一次介绍`高阶映射/多变量映射(multivariable)(函数)`的地方。您注意到图形学中通常以高级术语引用它们。  
多变量映射本质上还是映射，只是其操作的集合内容被扩充为多值(每对值都是向量或所谓的"多变量、多参数、多输出")，仅此而已！记为`f: [x,y,..] -> [z,..]`或`[...] = f(...)`。讨论高阶函数的域和像时，所有值才构成通常的概念，而单个值或分量仅表示它们的组成部分，要强调的是知道它们的每个部分都参与在映射中。  

层集(level set)是一种特定像的域集的一种说法。2D层集也称为层曲线、轮廓(海拔)图(contour)、同值线(isoline)，3D中称为层曲面或同值面(isosurface)，对于更高者称为超曲面。这些术语有很多名称，但代表完全相同的意思(即本文中所描述的，像给出的域集、变量对)。  
本文将这些环状物称为一种`值环`。  

隐式方程在各个值环上秘密地构建了某些图形，其偏移的绘图很可能是类似前者的。图形不一定是关闭的，例如抛物面(面不是关闭的)。单个值环是2D曲线边缘或3D曲面，而然要注意。我们一般必须基于间隔才能有效绘制它们，连续值环会导致新的面积或体积的图形。扩展时，如`C->C+-1`，结果不一定是均匀的，圆可以变成均匀的环，球体可以变成多层均匀扩展的球壳。边界周围的细带是否均匀取决于该方程本身的特点，可能是它的梯度引起的！  

简化其复杂性是将隐式方程视为黑盒。其一它提供定义和构建图形的行为。没有轻松的数学方法可以直接计算该集合的具体值(例如，请通过代数说明它的边界在哪里之类的问题)。数值方法是最常用的，它告诉我们现在正好处于哪个环上，以及是否相对接近零环，这就像我们在空间中随处移动，直到探测器突然响起，而不是一开始就知道图形在那里。估值的三分结果分别表示位于、不位于(内外部)图形的表征。这确实是有助于确认图形位置的一种思路。这就是我们需要知道的第二个功能，你可以通过方程测试当前位置是否在图形上(或者环的区域上)。  
这就是为什么说隐式方程的图形总是隐含于方程的，因为您需要大量碰撞域来描绘特定的值环，因为`xyz = 0`中任何之一都可能导致无解。相反，评估参数方程直接精确连续绘制图形的部分，评估域完成时图形就完成了。隐式方程的图形在任何情况下都需要花费更多的查找成本。  
请勿修改！！ 请勿修改！！ 请勿修改！！  
一个容易产生的误解是当前将值环(估值)视为到零环的距离。这通常是不可能的，请不要这样做。当我们面前有一个隐式方程时，请只使用可用的方法。具体原因不在这里说明。  

**曲面切片(slices)**  
轴平行平面切片是一种分析曲面的方法。它可以在局部二维空间研究曲面的二维边界。如果沿着高度轴进行连续等距切片，边界的合并图称为`海拔轮廓图(Contour plots)`。  

#### 8.2 部分微斜度
回想一下，一阶函数的相关引发差异量比率差分结果——微斜度确实符合于斜度，这就是命名的原因。  
考虑高阶函数时，请注意差异量的值类型可能来自于向量(如参数方程，见下)，其结果不一定沿用二维斜度来解释。  

`部分微斜度(partial derivative)`是一种对高阶的差分方法(扩展)，保持域的一部分不动而只改变**单个值**进行引发研究差异量，然后就像平常做的那样。
```ruby
df/dx = limdx->0|f(x+dx, y) - f(x, y) / dx # 注意两个df代表不同的含义
df/dy = limdy->0|f(x, y+dy) - f(x, y) / dy # 标准记号是∂
```
如下所示，由于使用的域和像均为一阶，结果仍然为斜度。如果视无关量`y`为常量系数进行快速派生，也将得到与下列相同的结果。  
事实上无关量永远会留在派生中，直到被评估，这也就是为什么曲线会变得丰富的原因。  
```ruby
f(x, y) = x²y         # (y)x² = y2x
df/dx = limdx->0|(x+dx)²y-x²y /dx
                 ydx + y2x
      = 0 + 2xy
```
想象一下，当我们锁定具体的`y=1`曲线时，就相当于查看特定轴平行截面曲线依赖`x`的微斜度。因为该情况与`x² -> 2x`的独立情况完全相同。  
每个部分微斜度告诉我们其他域确定时，被差分的那个域上的曲线速率。  

在部分微斜度中，你很确定下方的长度就是`dx`，高度来自于`dE`，因此该曲线完美存在于域的附近。我们足够描绘出所有曲线。  

**梯度**  
`▽梯度(gradient)`是包含所有域上的部分微斜度构成的向量`[df/dx, df/dy...]`。`f`的梯度函数记为`▽f(xy): [xy]->[df/dx, df/dy]`，结果可被描述为某种`向量场(vector fields)`。有时此类强调向量结果的函数会被叫做`向量值函数(vector-value function)`。   
作为例子，`f(x,y) = x^2+y^2`将创建一个朝`+z`的指数曲面，就好像将`x^2`旋转一周。注意现在只能对两个变量进行差分，尽管曲面位置是三维的，域空间和梯度场是二维的。该二维向量场显示为从零点向四周散开，因为该值是`[2x,2y]`。一种关于梯度的属性是它指向`最陡上坡方向(direction of steepest ascent)`。这个意思是，它必然指向使**输出增加最快**的方向(同域的维度)。  
此例，二维梯度指向曲面"高度"增长最快的方向，指向必须是平面的，要注意高度实际上不是我们可以控制的，因为它是函数的输出……  
另一种方式是将二维函数输出压缩为海拔图再与梯度场进行比较，在这种情况下，梯度向量总是**正交**于该位置上轮廓线。
```ruby
\  / 3D surfaces(with outputs)    H=1  \H=2
 \/                                \   /\
---- 2D gradient vf && inputs       \.gv
```
梯度的概念表示高阶函数的整体"微斜度"(在域中指向的一个向量)，但现在可能难以理解。  

**方向微斜度**  
`▽v方向微斜度(directional derivative)`记为`df/dv`或`▽v = dot(▽, v)`，函数`f`的方向微斜度为`▽vf`。与部分微斜度的限制不同，它允许同时偏移所有域。  

我们尚未说明后一个等式的来源。再一次，我们回到其本质过程来确定每个细节，尤其是比率的数值类型，如下所示。  
```ruby
▽v = limc->0| f(x+cv)-f(x) / c   #c=1e-5 v=...
```
这个表达式除了有助于直接开始评估没有参考意义。相反，我们可以查看`dE`的不同表达方法，例如检查已存在的部分微斜度的提示。因此我们不立即移动到对角上评估差异，而是执行两个部分速率的独立移动来累积差异，并且我们认为这些过程可能相互抵消一些值，因为我们根本无法评估函数。  
这种角度可避免诸如`/dv`项在比率中难以解释的问题，因为我们只是拆分为多次查看的部分差异。  
```ruby
dE += df/dx(x) * (cv.x)       # 为得到差分结果而不是实际值，应保持v的差分状态
dE += df/dy(x+cv.x) * (cv.y)  # 第二次移动，切换到y轴，使用当前位置计算df/dy

# 因此
▽v=
limc->0| df/dx(x)*(cv.x)+df/dy(x+cv.x)*(cv.y) / c # 由于考虑c->0 评估第二个部分速率的位置差异可忽略不计
         c[(df/dx(x) * v.x)+(df/dy(x) * v.y) / c  # 因此使用初始位置的y速率 并且认为这种差异导致的结果差异可以被忽略
         ▽·v
```
现在我们知道了从方向上合成速率的合理性。
```ruby
▽v = ▽·v = v.x df/dx + v.y df/dy + v.z df/dz
# 为了得到一致的结果，v不应该随意设置大小，否则斜度也将不同。标准化它们得到可比较的速率
```
方向速率的意义来自于由标准化v分量分配的三个部分速率总和。注意`v`的标准化，否则速率将不一致。它们的存在也隐含地表明它们将在任意方向创建不同的曲线(因为这些合成速率)，另外，**方向本身**就存在，梯度将提供所有部分数据。  

为什么梯度方向使增长最快？首先方向速率本身是根据梯度和方向选择合成的，任何方向都比梯度上要慢，因为其余弦项降低。
而梯度本身是由曲面定义以及其部分微斜度构成。具体来说，此时选择方向只是梯度的标准化向量。  
```ruby
max(dot(▽, u)) = len(▽)*1*1
```

**差分参数方程的补充(U2.4)**  
之前对参数方程的讨论中，我们研究了参数方程的比率项分别是两点距离的向量和一个单值参数因子，因此差分时得到的微斜度只是前者的修正。  
这种区别非常有意思，因为在这种3D空间中我们很难再看见三角形和斜度的简单往常直觉。  
相反，这种引发的微型变化是"3D"的。我们说当参数引发一点点时，您的位置就参考该方向移动一点(由参数映射即时算出)，然后我们就正确移动到目的地。  
进一步的，我们还发现三个映射分别从每个轴贡献派生速率，从而导致该整体的曲线引导速率。  
后面，我们还说明了计算参数弧的方法。本质上是拆分了这些速率并求解每个分量距离，然后合并以获得其长度的直线近似。  

每个子映射的派生`[Dxt Dyt Dzt]`表示曲线在此轴(向量分量)上的速率分量。派生结果是速率向量，通常是触线。

**曲率(U2.6/8)**  
曲线上某处的`曲率半径(radius of curvature)`是最拟合曲线的一个圆的半径(比其他任何半径都更拟合)，这是测量曲线在每个点的实际弯曲程度的好方法。
如果我们沿着曲线运动，从该点切入到曲率半径的圆上相当于以当时做出的瞬时弯曲程度圆周运动。  
`曲率(curvature)`的定义是该半径的倒数`k = 1/R`。其实际大小从某种速率计算`k = len(limds->0| dtag / ds)`。  
其中，`tag(t)`是所谓的`单位触向量函数(unit tangent vector function)`。这种触向量查询实际上来自于参数方程的微斜度的归一化，即我们已经说明过的参数曲线的速率。该向量会在不同的地方拐弯。  
接下来，`ds`是曲线的微小弧长。方向和该小步长因子结合在一起可以表明你转动的速度。  
```ruby
p(t) = [t-sin(t) 1-cos(t)]

# 计算原始tag函数
tag(t) = normalize(Dpt=[Dft Dgt])
# 接下来根据定义公式，曲率需要用ds对tag差分。这是不可能的，因为ds不直接影响tag(t)

# 而然，
dtag / ds = (dtag/dt) / (ds/dt)
# 如u2.4所述，参数速率是距离(近似ds)除以dt。
          = Dtagt / Dpt
k = len(Dtagt / Dpt)
```

**向量值函数的部分微斜度/参数曲面(U2.7/8)**  
这要求向量值函数至少具有多维输入(因此才可以部分差分！)。  
派生中我们使用与部分差分相同的技巧和原理，每个分量表达式的派生只有当前变量视为变量，而其他变量被视为一些无法评估的常数。  
```ruby
p(t,s) = [fts gts hts]
dp/dt = limdt->0|p(t+dt, s)-p(t,s) / dt

p(t,s) = [t²-s², 5t, ts²-st²]
           #xyz
dp/dt = [2t, 5, 1s²-2st]
```
要解释`dp/dt`时，我们可以考虑参数域平面中的一条原始参考线`s = 2`最后出现在结果参数曲面的位置(一条曲线)，该部分微斜度(方向向量)表示其附近的情况，例如`t+dt`。因此我们确定这是这条曲线上的触向量来表明速率，因为它会导致沿着曲线移动。有关"多维斜度"为向量的解释差异，请见u2.4。  
每个部分微斜度都与曲面该点相触，因为它们来自于多条重合曲线。

**二重积分**  
`二重积分(Double integrals)∫∫`(见unit4)是对多变量函数的积分。记为`∫y1..y2|(∫x1..x2|f(x,y)dx)dy`。  

您仍然可以从一维域的曲线下积分进行理解，首先表达式中间的积分称为内积分(组内的积分)，后计算的积分称为外积分。  
对于内积分，它尝试沿着给定的整个x域，对某个y值的平行切片曲线进行积分，这与我们的基本情况完全类似！  
不过，你可能会误以为这个时候需要一个实际的`y`来评估函数`f(x,y)`值，但内积分本身仅根据`dx`进行操作！应该将其展开为表达式考虑。事实就是，内积分是对`dx`的积分，表达式中的y项是对这个积分的常数项，因此该区域倍率可以放到外面(见属性)，从而很容易评估内积分的结果，这将得到一个与y有关的表达式，再积分外表达式，这是有道理的！  
```ruby
∫(∫xy²dx)dy   [0..2 0..1]

df/dx = y²                        # 观察部分微斜度
                                  # 部分积分的处理似乎与部分微斜度相关，可将无关项目视为积分的常数∫cf(x)dx

∫xy²dx = y²∫xdx
       = y²(AD(2) - AD(0))        # x²/2
       = y²(2-0)
                                  # 发现内积分的结果与y有关，这是有道理的(如上)，取决于选择哪条曲线
                                  # 内积分的过程本身与y无关，而只和x有关。而y的输入导致了可变的内积分结果
```
将顺序改为先计算y，结果一致。你可以从图形中获取类似的代替理解。  

如果不仔细进行分步骤积分而查看粗略结果，可以获得另一种观点。就其整合而言，由于函数的提升，现在摄取曲线高度扩展为曲面高度`h = f(x,y)`，细分间隔也将匹配更高的域`dA = dxdy`。记为`(∫+)Domain|fdμ`。其中`μ = dxdy...`与域的最小划分匹配。一般实际问题可能会用这种表达式，但本质、和评估上没有差别。  

一种常见的情况是，域不为固定边界，即在内积分时`x`的间隔可能依赖于y，这导致域来自于`x = ?y`的相关量，此时y还无关吗？实际上仍然无关，因为不影响内积分过程。画出该函数更容易理解该过程指定的四个边界。  
评估这种内积分仍然很简单，只是AD时会评估带有y的变量而已。  
```ruby
   |y|
  /  |     ∫x=sqrt(y)..x=1
/    |     ∫y=0..1
------x
```
