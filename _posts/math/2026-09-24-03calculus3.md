## MC1. 偏微斜度
多变量(multivariable)指的是关于向量格式的函数，即认为拆开每个元都是一个变量。  
`▼`两侧长度任意，含义任意。  

#### 部分/偏微斜度(partial derivative)
∂定义如下：  
```ruby
∂f/dx = limdx->0|[f(x+dx, yz)-f(x, yz)] /dx
```

`▼`给定点p，偏差分x时，物理坐标在x上移动，其f值变动的差异比。具体看法取决于两侧格式。  
例如，f(xy)->h的曲面上，令y=0，∂f/∂x相当于横轴上曲线的斜度，因为df为高度，dx为横轴距离。  
如果f的输出是个单值，根据操作——其他域确定为常数，结果完美对应被差分的那个域上的曲线速率。如果f不为单个值，则可能无法套用此情景。  

`▼`如果存在其他差分值，表达式应写为∂f/∂x，防止dx被消掉，但本质上和普通的dx没什么区别。  

#### 梯度(gradient)
▽定义如下：  
```ruby
▽f = [∂f/∂x, ∂f/∂y, ...]
```
给定一个函数点，输出其所有元的偏微斜度的格式。  

`▼`梯度的解释：您的意思是不是我从A，沿x走到一个点，再回去从y走到一个点，形成两个高度，三个点形成一个平面，那么期间任何一点的高度就由该平面近似，而与**函数本身在该点的值无关**。  
你如何假设这三点之间没有曲面？是因为微分成了平面吗？

`▼`如图所示是梯度的良好解释，两者都在使得"h"拉扯。  

`▼`因此，要"预测"某位置的函数值，使用两个已知速率的线性关系。**f(0)+(∂f/∂x)Δx+(∂f/∂y)Δy**。  

#### 关于梯度的问题
理解了梯度的基本概念，现在有一个问题，从点A出发，走出一个单位方向，使得函数值变化最大：  
```ruby
MAX(Δh = (∂f/∂x)Δx+(∂f/∂y)Δy)
```
根据我们推导的公式，即将单位长度分配给ΔxΔy，令H最大。  
此代数问题——这里得出了一个结论……Δx:Δy完全等于这两个偏微分值的比。  

因此，只要你沿着梯度方向走，函数具有最大变化的h，而无论x,y本身令h增加或减少多少。  

`▼`以上推导完全正确，完毕。  

#### 方向微斜度(directional derivative)
定义如下：  
```ruby
▽v-f = dot(▽, v)
```
为什么要定义这个？好吧，让我们重新看看单位向量对Δ项做了什么。  
由于单位向量的分量，这相当于把某些权重分配到∂的速率上，如果我们选择X轴(v.x = 1)，那么只会得到∂x。  
你会发现用来引导其变化的Δ项消失了，这时的结果实际上仍然是偏差分的结果，不能作为变化量使用。  
因此，我们要将Δ转移到向量的长度上，使Δf = (▽v-f)Δs。  

这告诉你通过三个已知梯度分值(由函数本身决定)，沿着某个方向的估计速率。同样，这与该函数本身在该方向上某个点的信息无关。  
但通常用于直接告诉你某个方向上的总体速率。  

`▼`总之，这就是正确的使用方式。切面上特定方向的斜度可合成性。  
`▼`除非这两个向量(当函数为单值输出，▽也为向量)重合，否则检查到其他方向的速率小于▽。  

## MC2. 微分多变量函数
#### 参数图形和隐式图形
`F(p) = 0`寻找其约束集代表的图形，数值方法很容易遍历所有位置，评估该点进行测试。  
相反，参数图形仅取决于主动参数，从而直接精确连续绘制图形。  

#### 微分单参数方程的几何意义
例子：若为单参数，输出位置，结果是极短两点间的向量(除以dt仅影响长度，取决于曲线情况)，该向量与曲线运动轨迹相切。  

`▼`回顾一下之前的术语可能有助于理解谁影响谁，t↑p↑，或者t↑p.x↑p.y↑都可以。  

#### 复杂的参数关系(链式关系)
一种复杂的差分是对f(x,y)，但其域来自一组参数方程，再问你t对f的差分。  

如前所述根据梯度的定义，f的整体差异(∂f/∂x)Δx+(∂f/∂y)Δy，我们再取Δx=【dx/dt】 * Δt。最后整理为：  
```ruby
Δf = [(∂f/∂x)(dx/dt)+(∂f/∂y)(dy/dt)]Δt
Δf/Δt ~= df/dt = dot(▽, [dx/dt, dy/dt])
```

## MC3. 算子
#### 曲率(curvature)
曲率的定义式是典型的两个看似不相关的量，dT/ds。其中T为"单位切向量"类型，s为走的一段曲线长度。  
也就是说，该比率检查此处走一小段，会引起多大的切向量方向变化。  

```ruby
dT = dNorm(DPtt)
ds = len(DPtt)dt
```

`▼`这里量的类型很复杂。另外上项dt实际上还需要套个len(dT)，超出了微分比率的含义。  
认为曲线经过的距离ds更复杂，先取切向量的长度，我个人最初理解认为len就够了，但定义中要求继续乘以dt。这里似乎要求视切向量的长度视为一种速率，距离必须为kΔt的形式，因此组合成ds = kdt。  

#### 快速派生偏微分
在计算偏微斜度时，请见其他变量视为常数(并根据规则操作)，对特定变量进行主要派生。  
```ruby
∂[t²-s², 5t, ts²-st²]/∂t = [2t, 5, 1s²-2st]
```

#### 散度(divergence)
`▼`观察向量场v->p(v)有几个有用的属性。  

算子div定义如下：  
```ruby
div-f(v) = ∂f.x/∂x + ∂f.y/∂y
```

`▼`该定义来自于几何含义，想象一个点附近的向量场，∂f.x/∂x告知从该点+dx时，向量场的X分量较原来如何变化。  
因此>0时，x更大，(类似于流体流动)说明外面x流速增加！再一个例子，如果本身为0，而<0，说明与dx方向相反，那么外侧流速比内部大，且中心为0，就说明流入此点。更复杂的情况见具体。  

`▼`相加后，汇集了以下各方的不同影响，确定给定点附近流体密度是增加还是减少的指导原则。  

#### 旋度(curl)
算子curl定义如下：  
```ruby
curl-f(v) = ∂f.y/∂x - ∂f.x/∂y
```

`▼`我仅学习2D旋度。三维扩展复杂。  
`▼`该定义，检查该点附近的向量是否构成一个顺序圈。回答一个问题——有没有转圈圈的趋势？  
类似于散度，这些验证情况可由∂f.x/∂x，以及∂f.x等情况组合而来。但这个我没有推导过，以后要推导直接去看那个文章。  
`▼`符号代表旋转顺逆，大小表示强度。

## MC4. 多元积分
#### 测度积分
`▼`这是我自己的评论：我建议只关注该表达式的直接告知目的，而不是需要费力解释解构项的变化。  
好吧。在一维积分中，你在x的线段上截取拼贴，而恰好每个截取都有特定xi与f对应，最终获得了这些总和。这就是所谓的曲线下面积的含义。  
这里实际做了什么可以更抽象，xi和f实际上是域和像，而你扫描的是特定的域空间。这种对应很难直觉找到，因此我才说费力。  

`▼`在3D正交坐标系下，这种域可能是小立方体以及对应的某些函数属性(如空气密度)，在2D正交坐标系下，这种域可能是微小矩形，函数可能对应二维参数曲面高度。  

虽然理解上更难，总之，笔者更喜欢图形学以及技术文献中经常使用的更简洁的测度形式：  
其中dμ是一个匹配f域形状的最小量。  
```ruby
∫domain|f(μ)dμ
```

`▼`这种形式∫S|(1)du的积分纯粹就是计算域的大小。

一种微元的转换类似于这个：y=x²的曲线长度积分。  
在这里，ds仍然是那个勾股等式，但通过对两侧隐式派生，得到dy/dx之类的项，完全消去ds中的y项，因此可以只通过x元积分。  

一种微元的转换类似于第一个例子(同样考虑参数方程)，ds仍然保持此几何关系，dx,dy项仍然需要被替换。  
我们知道Δx = kΔt这种经典扩张法，那么不妨dx = (dx/dt) dt。有时非比项的单独dx项，可以转成这种与其比相关的形式，基于Δ操作。  

`▼`令Δv等于dv的情况之前就已经经常使用过并被默认了，我当然不反对这种思考，毕竟这种比例是存在的，但注意每次注意这种差别和严谨性的预示。如果这种假设不能成立，那么所有结论都可能崩溃。  

第二种别名是ds = len(DPtt)dt，解释为切向量长度作为速率，乘以dt来近似ds。  
这只是另一种表达方式，结果完全相同，类似于测度的简化思想，同样，它能很好地推广到更高维度。  

综上所述——被称为参数方程的线积分，简化和别名等等一起就是：  
```ruby
∫C|fds = ∫t1..t2|f(p(t))len(Dptt)dt
```

#### 梯度定理
```ruby
∫C|▽f·(Dptt dt) = f(p(b))-f(p(a))   # 后两项是切向量被取消缩放，两点之间本身的向量
```

`▼`仅供参考……不证明(使用上面的链式关系)。这计算路径上的方向和梯度场的点积。有两个属性：閉合迴路做功恆等於零/路徑無關性。在实践中再说。  

如果向量场F(上述公式中替换梯度)任何闭合曲线在这个线积分中都等于0，像梯度场，就称为保守场。  

#### 二重积分
其记号如下：  
```ruby
∫Y|[∫X|f(xy)dx]dy
```
首先积分dx，得到y为不定常数时下任意x已积面积，再乘以dy获得"体积"，并且再令该表达式沿着y进行积分(采样dy,dy,dy)。  

`▼`这种解释当然是合理的，从数值角度也是对的。因为体积切片是一种柱状近似。  

`▼`如果域包含另一个变量(通常是无法表达为自己必须代替)，则视为常数，类似于不当积分的操作。
