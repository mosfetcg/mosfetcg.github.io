#### 转换
转换时，角度为X+轴的逆时针夹角。转换坐标为`rcosθ,rsinθ`。  
从后者反算角度时，使用`arctan(v.y/v.x)`，再根据其象限照表：  
```ruby
# arctan返回值[-90°, 90°]
Quadrant(象限) Result
Q1
Q2            +180
Q3            +180
Q4            +360
```

#### 微分元
在这里，如果均匀铺开r,θ如下图，drdθ导致的每块蓝色区域dμ不是规则的。远处的下底边为rdθ，因此一块近似为dμ=rdrdθ。  

`▼`在微积分中，通常已经约定dθ用RAD角度值差分。因此直接对应弧长。  
`▼`因为乘了r, 外侧去乘以被积函数会更大，修正了面积影响

## 柱系
柱系位置为(r,θ,z)。  

#### 微分元
其三重积分dμ=rdrdθdz。  

## 球系(spherical coordinate system)
球位系位置为(r,p,a)。  
两个角分别称为`极角(polar angle)`，是**极轴(polar-axis)**天顶参考方向与半径线的夹角、`方位角(azimuthal angle)`是半径线绕极轴相对于X+底面旋转的角度。

#### 转换
```cpp
// 通常我喜欢Y轴朝上，那么以极角y = rcosP
vec3 p = vec3(rcosAsinP, rcosP, rsinAsinP)
polar = acos(y / length(p))
azimu = atan2(z, x)
```

#### 转换
```ruby
p = a + β(b-a) + γ(c-a)
p = (1-β-γ)a + βb + γc

let α = 1 - β - γ
p(α,β,γ) = αa + βb + γc
```
