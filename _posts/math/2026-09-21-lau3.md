##### 正交补空间
一对子空间(例如它们处于父R^n下)若互为`正交补(Orthogonal complements)`，声称其所有向量互相正交，记为`P & P^perp`。  
首先再次确认这样找到所谓的补集是否满足子空间的定义条件(见上条件)。  
```ruby
P^perp{a, b}, P{v}   # P^perp是线性的吗？a+b、ca？
(a+b)·v   = 0+0 =0
ca·v      = c(0)=0
```
##### 1.默认的正交补
之前已经出现过两对正交补。为什么C(AT)与N(A)一定正交？它们是默认的正交补对。证明相当繁琐。  
在零空间的求解中(矩乘(1))，v集代表零空间。是否能找到v与某些矩阵向量的垂直关系？  
因此是那些行，即行空间；这就是为什么行空间总是和零空间相对出现，这些向量必定垂直。  
```ruby
A*v = 0;
Ar1v = 0 && Ar2v = 0...
```
##### 2.四个子空间(rank and nullity)
从倒转AT的列空间(行空间)来看，列数N可以分为其阶和零量(见上)。因为一个代数要么是pivot，要么是自由变量。  
由于倒转前后阶不变，原来的阶是矩阵的列空间，同样存在这样的关系。并且它们是一对正交补集，**相加为倒转的列数或原来的行数**。  
```ruby
rank(AT) + nullity(AT) = n; # C(AT) N(AT)
rank(A)  + nullity(AT) =
->
dim(C(A))+ dim(N(AT))  = n;
dim(p) + dim(p^prep)   = n; # 因此一对正交补的基础各占这个数字的一部分；
```
##### 3.正交补的向量对
现在考虑从正交补中选出的向量对，例如`N(A),C(AT){v1, v2}`。根据定义，互相垂直。  
在上一节，我们知道正交补的维数来自pivot项和自由变量，非常有可能互相独立(以上还没有明确证明)，所以应该不存在交集。现在给出它们的图像，这里要说明它们唯一的交点是零向量，也同时能证明它们是独立的。  
```ruby
v·v = 0 = len(v) -> v1=v2 = [0]
# 通过验证集合的定义，对于正交补集的图像，0是它们唯一的交点

# 现在要证明这两个基础是否有可能互斥。显然它们分别是正交对的基础，但是否每个基础都和对方的不同？
# 换句话说，如果把两个基础加在一起还是基础的吗？
span(v1) + span(v2) ?= span(vn)
# 证明是通过分开它们
span(v1) = 0; # 独立
span(v2) = 0; # 独立
-> span(v1) + span(v2) = 0 # 必全为0；
# 这给出，向量对是整体列的基础。R^n中的任何向量
v1(k) + v2(n-k) = v(Rn)
```

##### 5.特定变换目标在行空间(与零空间对)的特解(Unique rowspace solution)
继续之前，您需要仔细回忆零、列空间是什么。输出是列空间的线性组合。  
对此的解集是N(A) + vp(见上)。  
零空间的补是C(AT)。这里我们选择就让vp落在C(AT)上。并记它们为vr, vn。尝试找到行空间内对x的解是否存在(这意味着它们应该在某处重合)。  
```ruby
vr = v - vn                   # 已经说明它们的和必须是N阶
-> A*(v - vn) = x - 0 = x     # vr的确可以作为x的一个解(因为他不在零空间内)
```
接下来选择C(AT)中的另一个；其差vr - vr2同样还在集合中。这导致它们必须相等，这给出vr是唯一的；vr是行空间内对x解的唯一向量。
因此，行空间只有一个解与零空间的解组合为目标解。  
请证明：没有其他解(例如不在行空间)比这个特解还小。  
```ruby
A*(vr2 - vr) = 0 -> N(A){vr2-vr}
vr2 == vr;
```
下面给出一个具体例子。有线性子空间N(A)=span(v1)、C(AT)=span(v2)。因此，可以构成总体的二维向量。  
其图像特征是两条正交线垂直并经过零点(见正交补的独立和交集)，由于它们不是相反的，组合构成一个平面。  
如果再画出零的偏移(rref形式)，它们是与零线平行的线，它仍然可以与C(AT)正交(因此这就是为什么有一个特解)。  
既然该平面空间由这两个子空间表示、零线可以随意移动，这里存在一个特别的几何关系。  
```ruby
\R /N   /X
 \/    /
(0.0) \vr
```

##### 正交投影
现可扩展投影计算到**任意维数的**子空间，记为`ProjV(x)`(onto subspace)。  
这是从上述一般的正交集以及其图像推断的。例如ProjNA(x)、ProjCAT(x)的情况：  
零空间的偏移解线(给定任意点)到行空间的投影是由这两个对集的组合构成的直角三角形。如果我们把行空间看成要进行投影的子空间，将输入放到零空间的偏移中，这可以得到任意点对行空间的投影。后续还将一般化这个结论。  
```ruby
# 在三角形中，记零线某点(x,y)，偏移为如下点。这三个点可以由任意这两个子空间的向量组合
ma + nb = x+vp.x, y+vp.y

# 一旦给出具体的(x,y)(也必须给出)才能计算具体投影，而不是考虑这些代数
# 这样只需要找到它们的基础需要多少缩放，其中一个就是投影
projCAT(x)
```
为什么可以是任意的子空间？某个子空间作为正交补对时，另一个也伴随而来。只要找到想要的正交补对。  
证明：计算子空间的投影是一种线性变换。  
一般形式是`ProjV(x) = A(ATA)^-1AT * v`。V是想投影的子空间，例如2D平面；输入v可以是其他空间系统，例如3D空间位置。例如将v投射给2D平面V上。  
```ruby
# 将正交补向量写成其基础的矩乘，此例用的是零空间和行空间
V = C(AT)
vr = span(V) = AR(row_bases)*(y1,y2...)

ProjR(x) = AR*y     # 投影即行空间的缩放，如果根据与零空间的关系如果将其作为特解
x = AR*y(vr) + w
x - AR*y(vr) = w    # w是另一个向量，W在零空间

# 简化A = AR
# 倒转后，左零空间仍然输出0，这给出
AT(x-AR*y) = AT(x-ProjR) = 0

# ……复杂
-> ATx - ATAy = 0
-> ATx        = ATAy    # ATA可逆(见倒转)，找到它的逆变换
 (ATA)^-1 ATx = (ATA)^-1 ATA y
              = I y
            y = (ATA)^-1 ATx
          A*y = A (ATA)^-1 ATx ...
              = ProjR(x)
# 这给出对V的投影是某种线性变换矩乘。其中A是V的基础
```
投影示例。计算其投影矩阵。  
```ruby
V = span([1001][0101])

# ProjV: R^4 -> R^4;
ProjV  = A(ATA)^-1AT * v
         = 1/3...[4X4]
```
输入`x`得到的投影`proj`是子空间中离它最近的向量。另取平面(子空间)一向量`v`构成三面体的长度是？  
**最小平方近似(Least squares approximation)**  
```ruby
||x - v|| >= ||x - ProjV(x)||
```

##### 正交基础
含多个互相正交的标准化向量(可能是"倾斜"的)的子空间，称为`正交集(orthonormal set)`。  
使用正交集可以用来建设良好空间系统。  
```ruby
V{v1, v2, v3...} if len(vn)=1 && vi·vj=0 && vi·vi=1
# 这是一个单集线性子空间
```
简化使用正交集的子空间的投影。一般形式`AAT(x)`。  
```ruby
V{v1,v2,...vk}{v} V^perp{w}

x = v+w = projV(x) + w            # 为了找到投影，正交集的一部分和其正交补的一部分
v = projV(x) = c1v1+c2v2...ckvk   # 分解v

   x = (c1v1+c2v2...)           + w
vi·x = c1viv1+c2viv2+...        + vi·w
     = c1(viv1)+...ci(vivi)+... + vi·w
     = c1(0)+c2(0)+ci(1)+...    + 0
# 这是什么？一个纯量
     = ci

projV(x) = (v1·x)v1 + (v2·x)v2 + (vk·x)vk
         = A(ATA)^-1AT
         = A Ik AT
         = AAT * (x)
```
