## SP1. 数据定义1
#### 方差(variance)和标准差σ(standard deviation)
```ruby
σ² = Σ(xi-mean)² / n
σ  = sqrt(σ²)
```
数据分布越分散，由于差均值的平方求和，标准差就越大。  

样本方差、样本标准差，关系类似。  
```ruby
σs² = Σ(xi-mean)² / (n-1)
```

#### 平均绝对偏差(mad)
```ruby
MAD = Σabs(xi-mean) / n
```

#### Z分数
衡量一个数据点高于或低于平均值多少个标准差。  
```ruby
z = (x - mean) / σ
```

#### 百分比柱图
分框柱图逐步细分cate时，就变成一条曲线了。即密度曲线，曲线下积分为1。取出特定区域的统计时，需要积分。  

#### 残差(residuals)
线性回归时点距直线的垂直距离，用Σres²尝试回归称为最小平方回归(least squares regression)。  

## SP2. 统计问题
#### 原理
对一个总体做出有效的统计结论，样本必须具有代表性，无偏。  

代表性是与总体整体特征结构相符的完美样本。  
偏差是系统性错误的引入，强烈偏向特定结果的样本。  

随机抽查的目的就是为了降低偏差。  

但如果不进行全面调查，能验证特征分布结果就是真的吗？统计学的目的是让我们具有高度信心确认这个结果。  
随机抽样的样本够多时，真实比例就会收拢。  

#### 随机抽样
如果样本不是随机选择的，那么它很可能存在某种偏差，并且数据可能无法代表总体。  

好的采样方法：
简单随机抽样，分层随机抽样(每组单独抽)。

## SP3. 概率
存在通过模拟得出事件概率的科学机制。满足特定事件的样本/除以总样本得出概率，以下为一般公式：  
```ruby
P(A) = Σa / n
P(A&&B) = P(A)P(B)               #独立事件组合概率，典型的是抛硬币
P(A||B) = P(A) + P(B) - P(A&&B)  #独立事件任意发生之一，需要减去共同概率
```
非独立事件(相关事件)具有条件概率：典型是类似于多次抽牌的后续情况。  
连续摸出两颗绿色珠(不放回)。第二次概率需要重新计算绿色数量/总数，再以乘法规则计算。  
假设一共5珠3绿，概率为60% * 50% = 30%。  
```ruby
P(B|A) #  |表示在右侧条件A发生的情况下B才发生的概率，在独立事件中，该概率等于P(B)
P(A&&B) = P(A)P(B|A)
``` 
这里A是第一颗绿色，B是第二颗绿色，两者概率容易计算，而组合概率通常需要公式解。  
如果给你了数据，那么通常P(男&&上班)的概率直接可以得出，可以反推其他部分。  

#### 排列(permutations)
类似于顺序安排独立步骤项。  

例如汽车引擎X颜色，步骤是选引擎和颜色；入座问题，就是按座位顺序考虑，那个步骤决定哪几个人可以坐进去。  
前者独立，后者不独立。  

#### 组合(combinations)
握手问题，按照排列，可以AB,BA(符合第一步骤有两个，第二步骤只有一个)，视为同一个结果。  

#### 随机变量(random variables)
随机变量不同于一般变量。在代数上是一个遵循分布的可能随机值，结果通常是发生的具体值。  
当然，分布和结果可能是离散的，也可以连续的。  

#### 期望值(expected value)
表示随机变量表现结果的均值。「每一種可能的結果」乘以「該結果發生的機率」。通过概率分布权重调出最终均值。  
既然有概率分布，就相等于从大量具体样本计算算数平均值。  
```ruby
E(X) = Σxp(x)
```

#### 概率密度函数(PDF)
连续型随机变量的分布函数。  

类似于之前的"百分比柱图"，取出特定值需要选取范围和积分面积，**单个值的概率是0！，总面积为1**。  

#### 多变量期望值
均值直接合并，不論這兩個隨機變數彼此之間是獨立還是互相影響。方差需要独立才能合并。  
```ruby
E(X+Y) = E(X)+E(Y)
Var(X±Y) = Var(X)+Var(X) #独立时，波動（不確定性）只會越疊加越多，不會互相抵消。
                         #當變數之間不獨立時，它們的波動可能會完美地互相抵消
```

#### 二式随机变量(binomial)
特殊随机变量：结果只有两种可能，成功，失败，实验独立，实验次数固定，每次成功几率保持不变。  
注：其结果是成功次数。

#### 几何随机变量
需要尝试多少次，才能迎来第一次成功(值转为1)。其期望为1/p(单次成功概率)。  

#### 大数定理(law of large numbers)
样本均值最终逼近确定期望值，如果样本数量极大。  

#### 10%规则
統計學上有一個10%規則（10% Rule），只要你抽取的樣本數量不超過總數的10%，即使抓完不放回去，我們也可以當作每次抽取都是「互相獨立」的。  

#### 抽样分布
从总体中抽取样本估值整体特征参数时，样本的统计量结果也是随机的，这些统计量呈现的分布。  

例子：扭蛋机有60%的黄球，一组抽10个，反复抽，这些结果的分布。  

样本量(每次单独抽查中)的数量上升(建议>30)，该分布就会最终呈现正态分布，中间值接近真实情况。  
频率最高的样本统计，接近真实情况，而不用管母体什么样，这称为"中央极限定理(Central limit theorem)"。
