## 5. 处理变换2
#### 线性变换以矩阵向量乘法表达
```ruby
# /v/linear-transformations-as-matrix-vector-products
# 
Ici            # I基
x = I(x)
  = span(Ic, C = {x.values})
x = Σ xi * Ici

T(x) = T(Σ) = Σ T(x1Ic1)        # props
            = Σ x1 T(Ic1)       # props
            == [T(Ic1)... ] * x # 这表明一个线性变换T，以几个列基变换结果一起描述
                                # 左侧函数很抽象，矩阵中的T(Ic)通常是已知量(该变换对Ic的影响)，所以反过来描述了T。  
```

`▼`I矩阵的基不要使用奇怪的coli = 1，或者ei等符号。  
前者主要是因为当时我只想有必要强调了其"形状"(这不是瑕疵)，表达式并不容易，既然应用在此，那么有必要才在这里说明一下。  

从I矩阵开始描述目标变换，一般是为了将Ici强调作为参数背景板参考，然后替换成某个T(Ici)。  
```ruby
A = { I -> [T(Ic1)...] }
```

`▼`这里就是这样，基变换就是独立考虑的，因此在函数组合中依次传递。本来有些理解奇怪的点，幸好剥离出来了。  
组合就是基的连续变换。  

#### 基方阵逆方法
```ruby
# 逆的表达式定义和一般行为
T^-1(v) = A^-1 * v     # 逆变换同样是线性变换，并且具有同样线性属性，因此存在某种矩阵，记为：
rref(A) = In           # 根据可逆条件，该结果是必然的
T^-1oT = In
A^-1A = In
```
一般的逆方法基于单位矩阵和变换乘法，非常难以理解。反正也没有证明。实用算法如下：  
```ruby
A = [cols]

# rrefCol 指完成一列。
cols.each
  mat_A1 = rrefCol(A)  # 记录下需要的行操作，并以相同的单位矩阵记录
  new i = I^n
  mat_S1 = syn(i)      # 将行操作同步
# 注解：
# 结果中，A1 实际上等于 
[ mat_S[A.col1] mat_S[A.col2]...  ] = mat_S1 * A # 根据乘法定义
                                    = mat_A1     # 实际上等于A1
# 如果我们重复每个列
mat_A1 -> mat_A2 -> ...I
# 并且每个同步
mat_S1, mat_S2 ...

rref(A) =  ... * S2 * S1 * A
        = ? # I

# recall
A^-1A = I
{S} = A^-1
```
检查，这获得一种工具。  
```ruby
during rref
A-> S1A -> S2S1A -> ... -> I
# 假设一个I对其使用得到的S
I-> S1I -> S2S1I -> S3S2S1I = A^-1I
                   # ↓
rref[A | I] => [I | A^-1]
```
某些经验公式由该工具导出。det的定义检查有逆的相同代数条件。  
```ruby
# 2x2                                         # B
A = ab  A^-1 = d/ad-bc -b/ad-bc = (1/ad-bc) [d -b
    cd        -c/ad-bc  a/ad-bc             -c  a]

# determiant for M is
Det(M) = |M| = || = ... # 判别式

Det(A) = ad-bc!=0       # invertable determiant
A^-1   = 1/Det(A) B
```
下面的扩展形式也仅作公式使用。  
```ruby
# nxn determinant
# Aij 除去此序号一行一列的小矩阵

# 沿着任意一整行和一整列给出结果
Det(A) = a11Det(A11)-a12Det(A12)+a13Det(A13)-+-+...a1nDet(A1n)

```

#### 判别式2和倒转
非常可选。  
```ruby
det(B) = k^n det(A)        # for each Br= Ar*=k row, n row total.
det(X)+det(Y)=det(Z)       # identical X,Y,Z except for only one row you have Ar + Br = Cr
det(Aij) = -det(A)         # Aij swap the i,j row of A
det(Aij) = det(A)          # Aij, in row j, let Arj = Arj - cAri of A
# upper/lower triangular matrix 对角一侧全为0，即上下三角形矩阵(上：右上有值)
det(Aup) = a11a22...ann
# 三角化简判别式。按照对角元素顺序用上述技巧进行简化，直到获得对角值。注意三角化不是rref!
```

`倒转(transpose)`记为`A^T/AT`。对原矩阵交换行列向量。实用属性如下。非常可选。  
```ruby
det(AT) = det(A)
(AB)^T  = B^T * A^T
(A+B)^T = A^T + B^T  # 可用于 (A^T)^-1 = (A^-1)^T
# dot(v^T, w) = v^T w  略，不要使用
# Rowspace C(AT) left nullspace N(AT) 略，不要使用 
# ... 7末尾略。
```
