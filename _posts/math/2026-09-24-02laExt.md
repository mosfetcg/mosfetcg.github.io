## 5. 处理变换2
#### 线性变换以矩阵向量乘法表达
```ruby
# /v/linear-transformations-as-matrix-vector-products
# 
Ici            # I基
x = I(x)
  = span(Ic, C = {x.values})
x = Σ xi * Ici

T(x) = T(Σ) = Σ T(x1Ic1)        # props
            = Σ x1 T(Ic1)       # props
            == [T(Ic1)... ] * x # 这表明一个线性变换T，以几个列基变换结果一起描述
                                # 左侧函数很抽象，矩阵中的T(Ic)通常是已知量(该变换对Ic的影响)，所以反过来描述了T。  
```

`▼`I矩阵的基不要使用奇怪的coli = 1，或者ei等符号。  
前者主要是因为当时我只想有必要强调了其"形状"(这不是瑕疵)，表达式并不容易，既然应用在此，那么有必要才在这里说明一下。  

从I矩阵开始描述目标变换，一般是为了将Ici强调作为参数背景板参考，然后替换成某个T(Ici)。  
```ruby
A = { I -> [T(Ic1)...] }
```

`▼`这里的理解比较重要。  

#### 解释组合变换
```ruby
# /v/compositions-of-linear-transformations-2
Cx = B(Ax)
                              # 变换就是一组Ic变换描述的。那么左右两侧应该匹配。
C = I                         # 先设为I
C = [B(A(Ic1))..] = [B*Ac1...]# 因为只能继续输入到B中(根据等式走向)，所以……
                              # gotcha?
```

`▼`这里就是这样，基变换就是独立考虑的，因此在函数组合中依次传递。本来有些理解奇怪的点，幸好剥离出来了。  
组合就是基的连续变换。  

#### 基方阵逆方法推导
根据存在逆的条件，对应地rref(A)必然显示其基——结果为I。并且**A^-1A = AA^-1 = I(1)**。  

当您使用rref(A)时，列会化简，如前所述，拿每对列来看，这相当于执行特定的列变换，可找出此矩阵。  
```ruby
rref(A) = A1
[S[Ac1] S[Ac2] S[Ac3]...] = A1
       # that is, just SA = A1
```
持续该过程，直到等于I。根据公式1，左侧就是逆矩阵。  
```ruby
(S)(S)(S)A = I
```
原理检查完毕，但最终需要找出这些矩阵。  

`▼`我没有实际具体找过所谓的S。  

#### 并列求逆算子
为了避免写出中间矩阵，求逆实际过程使用增广矩阵来扩大原矩阵，两侧会同时变化，分隔符仅起视觉效果。  
对左侧，A逐渐变为I，右侧会逐渐被中间矩阵累计，最终得到逆。  
```ruby
rref[A | I] => [I | A^-1]
```

`▼`这种方法你只需要正常rref就好了，不需要依靠理解中间矩阵变换的概念去做。当然他俩是同时存在的。  

## 6. 判别式(determiant)
#### 2X2判别式
当你代入求逆算子对2X2矩阵Cols[ac bd]，会得到：  
因为分母不能未定义，ad-bc！=0，该分母称为`Det(A)`。这是在假设算子中可逆情况下的不可逆条件。  
```ruby
A^-1 = (1/ad-bc) [d -b
                 -c  a]
```
`▼`当作结论。因为只是代数计算。  
`▼`det符号有时写为两个竖线。  

#### N矩阵判别式
对于更大的方阵。你需要递归计算。  
```ruby
Aij
# 除去此序号一行一列的小矩阵

# 沿着任意一整行或一整列给出结果
Det(A) = a11Det(A11)-a12Det(A12)+a13Det(A13)-+-+...a1nDet(A1n)
sign(i,j) = -1^(i+j)
```

#### 判别式萨鲁斯法则(rule of Sarrus of determinants)
一种视觉规则，整理Det代数后，每个项类似于对应一个斜线上的数字乘积。  

#### 判别式简化运算
`▼`一些属性。  
```ruby
det(B) = k^n det(A)        # 一行缩放k，每行都使N+1
det(X)+det(Y)=det(Z)       # identical X,Y,Z except for only one row you have Ar + Br = Cr
det(Aij) = -det(A)         # Aij swap the i,j row of A        # 推论：带有重复行时，矩阵不可逆
det(Aij) = det(A)          # Aij, in row j, let Arj = Arj - cAri of A
# upper/lower triangular matrix 对角一侧全为0，即上下三角形矩阵(上：右上有值)
det(Aup) = a11a22...ann
# 三角化简判别式。按照对角元素顺序用上述技巧进行简化，直到获得对角值。注意三角化不是rref!
```
#### 2X2判别式等式列基平行四边形面积
(结论)经过一系列复杂变形，该结果等于列构成的面积。  
判别式的几何直觉就是面积的缩放因子。  

#### 倒转(transpose)
`▼`非常可选。  

倒转A——交换行列向量，记为**At**。  

参考属性如下：  
```ruby
det(At) = det(A)
(AB)t  = Bt * At
(A+B)t = At + Bt  # 推论： (AA^-1)t=It，所以  
                        (At) <-> (A^-1)t  #互逆
                        (At)^-1 = (A^-1)t
```
