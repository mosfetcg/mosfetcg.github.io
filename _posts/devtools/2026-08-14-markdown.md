`markdown`语法兼指南编排指南，通用性指导已转移。下面开始的格式可以直接使用。选色：[ru](https://flatuicolors.com/palette/ru);[fr](https://flatuicolors.com/palette/fr) 
```md
## 标题`(xx-)`
<style>code{color:#004be9}nav a{color:#004be9!important}</style>
<nav style="position:fixed;left:0;bottom:0;">
[返回](#top)/ [返回](#top)</nav>
```
## 标题`(?[rgb|name])?` 
<style>code{color:#004be9}nav a{color:#004be9!important}</style>
<nav style="position:fixed;left:0;bottom:0;">
[返回](#top)/ [返回](#top)</nav>

## 内容正式标题內容正式標題内容の正式タイトル
#### 标准编排种类
`文`：二级大标题；样式/目录(开始的部分允许间隔但不强制);之后放入第一个二级大标题(通常应当放入水平线和前置段落行)；  
禁止一级标题  
`小文`：唯一二级标题表示主题；偏好四级标题，间隔行

### 语法参考

| 元素 | 句法 | 注意事项 |
| ----------- | ----------- | ----------- |
| 标题 | `#` | 在#和标题名称之间放置一个空格；有一种=-的代替语法 |
| 段落和断行 | `\enter`  | 段落以空白行分隔`</p>`，行末兩個空格産生斷行`<br/>` |
| 水平线 | `---` | 在一行上单独使用三个或更多星号、破折号或下划线 |
| 突出文 | `* *`/`** **` | 斜体使用一个，粗体使用两个，三个是同时使用 |
| 有序列表 | `1. `  | 数字不必按数字顺序排列，但列表应以数字一开头；支持嵌套  |
| 无序列表 | `+-* ` | 保持列表的连续性，将元素缩进四个空格或一个制表符； |
| 代码块 | \`\` | 连续三个符号则支持解析编程语言 |
| 連結 | `[連結](http://example.com)` | `<>`代替语法;标题可强调和作为代码 |
| 圖 | `![圖](url "title")` | |
| 引用 | `>` | 需要多个引用段落时可以用留空的`>`行分隔；嵌套使用双符号；其中也可以包含其他语法 |
| HTML | `标签` | |
| 转义 | \ \`\` | 等等 |
| 扩展 | | https://www.markdownguide.org/extended-syntax/ |
| 表格 | `|t|t| \n |-|-|` | |
| 脚注 | | |
| 自定义标题 | |
| 代办列表 | `- [x]` | |
| 高亮文 | `== ==` | |
