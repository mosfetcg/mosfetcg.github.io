音高(pitch)由频率(frq)决定。

## 半音
给定一个基准音，频率之比为1：2时（构成八度关系），听起来融合。  
给定一个基准音，频率之比为2：3时（构成纯五度关系），听起来和谐。  

在十二平均律中，给定一个基准音，相邻八度区间被划为12个连续完全等比的半音。相差n个半音计算公式为`f = f0 * 2^(n/12)`。  
当n=1时，指数部分为1.0594，n=12，则指数为2或1/2。  

▼在这种刻度中，任意挑选两个半音进行平移，距离听起来是类似的。  

可以利用这种刻度创建一个音阶，使每个选中半音至少有一个对应和谐音。但按半音顺序(刻度)可能不是和谐的。  
我们先检查哪些可能是和谐的：以基准音(1.0)开始，步进7个半音时为1.498(约1.5倍)可以寻找近似和谐音的频率。重复12次，这在数学上正好将原始八度刻度中的半音全部走了一遍，并且其降八度版本可以完美放回刻度中，且最后一次为128倍((2^7/12)^12)，精确回归第一个音符，这确保了不可能再产生其他和谐序列，且使C具有两个和谐音符。  
暂时从C~B命名它们。该顺序为：**CGDAEB-F#C#G#D#A# (GbDbAbEbBb) - FC。**  

如果我们选中头尾序列FC-C-GDAEB，检查其模12位置5,0,7,2,9,4,11，在重新按频率排序的刻度中分配给白键，最后，用A4=440 Hz规定所有音高，我们就能演奏这样的C大调音阶。  
剩下的音分配给黑键位置，借用相邻白键音名加上变音记号——升降号`flat-_b/sharp-#`命名。  

▼观察该序列，移调C->G仅改变一个新音符F#，这导致两组音阶非常相似，且其内部听感相同的情况下，用于转变乐曲。

## 大调音阶
大调音阶(scale)是白键模模式的所有移调变体，因此其递增半音集间隔都为2212221。注意，加起来正好12。  

*由于之前介绍的原因，所有调性听起来类似。*  

音阶中的音符特殊名称如下：
```ruby
1  2  3  4  5   6  7   8   # 等级和唱名(Solfège)
do re mi fa sol la si  do

1 8 tonic     主音
5 dominant    属音   高5度
4 subdominant 下属音 低5度(折回)
```

## 织体
按声部的特点分类音乐。  

单音音乐有一个单旋律，以及其一个其体现的声部。  
分支音乐有一个单旋律，以及其多个体现的同步变奏声部。  
主调音乐有多个声部和谐地同步进行。一般表达主旋律和伴奏和声声部。例如同步合唱。伴奏节奏可以错开，但基本同步和服务主旋律。  
复调音乐有多个独立旋律和节奏。例如，错开旋律和节奏的男女合唱。

## 调性和调号
作曲时，音阶调性在曲子中不变——或通常很长时间内不变。  
固定的一组关键升降号即可识别意图，这就是人们为什么写出和使用调号。  

这里规定其左右顺序与白键位置推导的音符顺序相同——升号为F,C,G,D,A,E,B。降号相反。  

次音阶的调性与其变体无关，基于自然次音阶。  
次音阶的第三个音总是比同名大音阶的第三个音低半音。  
关于大小音阶的关系和键签，请见下。  

五度环是相邻主音相差五度键签的环状排列，两侧递增#b的个数。只是一种可视化工具。  
自然音阶扩展了大小音阶，称为更明亮或黑暗，最亮的是利底亚。  

由于各种各样的音阶排列的不同升降符，存在许多键签的表示。有时也需要从键签识别音阶。  
有12个大调。   
下面是一种特定音阶升降符号个数的计算方式，首先需要记住7个：  
```ruby
# +N #的个数 
# -N b的个数
C主   0
D主   2#
E主   4#  +4
F主   1b  -1
G主   1#
A主   3#
B主   5#

Cb = -7  C=0  C# = 7   # 这很容易理解
C->c  -=3              # 计算次音阶
```
任何主音阶计算其b音阶或#音阶，取上面的对应值加减7。  

那么如何从一般键签识别大调音阶呢？注意资料未给出推导，按顺序给出的键签中，**最后一个sharp的位置(带上#)比主音低半步**，需要加上。  
而在降低符中，**倒数第二个**即是主音(带上符号)。  
除此之外，C主无任何符号，F主包含一个Bb。  

大调和小调之间存在两种不同的关系。  
平行关系指主次音阶共享主音。相对表示它们共享同一个键签。  
这意味键签可能对应两种音阶，主音阶和其对应的相对次音阶。相对次音阶的主音比其相对主音阶的主音低三个半音，请数一下(如有错，请见平行关系和相对关系)。  

键签将歌曲调性缩小到大调和其关系小调，作品的第一个音符和最后一个音符——乐曲通常以主音开始和结束。  
## 和音
**逆/转位操作(invert)**在音程中指对两个低高音符ab，将低音符提高一个八度。  
再计算音隙ba'时，全隙总是逆为其他全隙，四五互换；主隙和次隙互逆，且三六互换，二七互换。  
增强和降低互换。  

`和弦(chord)`是指三个或三个以上音符同时发出的声音，最初含义是指一致或和谐的声音。  

`三和弦(triads)`包含一个`根(root)`(最低位音符)，三音程音，五音程音(距离根)。根音符给出三和弦的名称。  
```
5th
3th
Root
```
大三(4)，全五(7)称为大三和弦(major triad/chord)，如`C-E-G`；  
小三，全五称为小三和弦(minor triad)，如`C-Eb-G`；  
大三，增五称增三和弦，如`C-E-G#`；  
小三，降五称为降三和弦，如`C-Eb-Gb`；  

音阶中每个音级为根导出的7个和弦集合称为`音阶三和弦(diatonic triads)`。  
根据其根的序号使用I-VII的罗马数字，大写表示大三，小写表示小三，附加加号和圆圈分别表示增和降。  

对和弦的音符组进行**逆**时，将操作或结果中的最低位音符称为`bass(低音)`。  
并且要将低音向上移动一个八度。当低音不为根时，就称为被逆和弦。  
其他两种低音的对应情况(3和5)称为第一逆，第二逆位置。  
此时的写法仍然保持根，但在后缀中加上，第一逆附加上标6，因为移动后的根比最低音高6，第二逆为6和下标4。  

另外，和弦中的音符可以处于任何八度而不影响其识别，而不是最紧凑的形式。  
`排列(voicing)`意味着使用相同的和弦进行作曲，只要最低音为该和弦的低音。  

七和弦则由三和弦和额外一个根至7音阶(seventh interval)的音符构成。其罗马数字右加一个7的标记。类型有点复杂，参考下面的记号。  
由于多一个音符，逆时会出现第三逆(七为低音)再进入循环。  
```ruby
COMMON TYPE                                                          ABBR
```
