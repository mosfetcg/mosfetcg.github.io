# 信号理论
该领域实际上是我们"像素的理解"进行配合的另一必要方面。  
像素点对被采样连续函数的采样是离散的。为了提升离散采样时的表现，则需要此理论。最好也知道在输出端，给定uv，其像素上的个数是有限的。可以理解为一个形状不变容器。意识到这一点以及保持采样的意识通常更容易理解。  

计算机不可能完整存储连续函数的数据，无论是音频还是图像领域。因为处理理论较早应用于音频，即各种波形，即(或函数)数据的被称为"信号"一词的来源。  
理解“像素是采样点的结果而非躺平的方块”，是提升图像表现的思维飞跃。  

简单的采样函数是各种一维基础波形。当然也可以是各种曲线，主要是波形是周期性的。  

## 卷积
卷积算子(convolution a★b)定义如下：  
```ruby
(a★b)[x] = SumOf a[x-t->x+t]b[r->l]
```
即类似于b反向量的点积。

b称为滤波器，有多种用途，例如全分配一个归一均值常数，那该算子就是对`a[x]`附近进行算术平均。

满足：交换结合分配。  
等身滤波器，返回单个原值`a = a*b`，可以使用运算率进行处理表达式。  

## 移动滤波器
另外，卷积的结果图像，可视为一系列偏移滤波器乘以其中心位于`a[j]`处的权重缩放后，叠加到一起的结果(影响位置取决于滤波器的宽度！)。  
这从代数上理解有点抽象，因为扫过这么多数据，真的会让某个位置a[x]的卷积就是这些波在此处的叠加吗。  
建议当作一种直觉。  
```ruby
(a★b) = sumOf a[j]b->j
```

#### 采样和重构(在该语境下)
从离散数据过度到连续函数称为重建，反之称为采样。用一个连续滤波器即可。  

图形学中通常讨论二维形式的相关问题，例如窗口大小为1时，采样九个点。这一定义可以采用与一维情形相同的方式来解读，
每个输出样本都是输入中某个区域的加权平均值，其中二维滤波器被用作“掩模”，以确定该区域内每个样本在平均值计算中所占的权重。

图形学中有几个常用的滤波器，其自然半径相对于单位采样距离定义，且权重积分应该为1。这是采样和重建过程中的必要条件，以确保不会改变信号的平均值。……(不就是一些密度函数吗)。

插值滤波器：如果一个连续滤波器在用于根据离散序列重构连续函数时，所得到的函数在各个采样点处的值恰好等于对应的采样值，那么该滤波器就具有“插值”特性——也就是说，它相当于是在“连接各点”，而不是生成一个仅在这些点附近取值的函数。正是指那些满足以下条件的滤波器：f(0)  =1，f(i)=0，非0整数。  

## 图像采样的伪影
在规则的二维网格上采样连续函数，只采样一次会怎么样？  
这些错误称为走样(aliasing)，如锐利边缘(如球)出现的锯齿”（jaggies），重复图案中出现的摩尔纹(moire patterns)(特别是纹理!)。

# 纹理
纹理处理涉及两个方面：纹理映射和抗锯齿(减少走样发生)。  

纹理映射是为表面3D点找到纹理坐标。存在几何双射方法和mesh顶点插值两大分支。  

抗锯齿设计遵循纹理的映射过程，首先，视口的像素看见一部分表面，然后表面去查找和采样某个纹理颜色。  
一方面，可以直接对图像空间的像素进行超采样，类似于光线追踪的做法，这会求解表面的区域平均值，自然会平均其纹理查找，但将消耗计算量，但只要采样数量足够，无需修改纹理映射机制本身，就能获得极佳的效果。  

另一方面是对受限的UV处的纹理本身(该像素覆盖的区域)进行平均滤波。如前所述，其时空关系是主要问题，用户在很少看见表面细节的地方，应该对其进行纹理级别的滤波。  
换句话说，我们需要知道该像素实时对应的纹理空间区域，然后计算其平均值。这是一个复杂的问题，因为涉及各种视角、映射方式、表面形状……  

图形学中的基本正确思路是，找到此像素命中表面点中心点p到uv的映射，然后对像素附近的xy对uv求导，求得此速率直接用已知的一对uv值以及速率去近似uv空间中的其他点，从而简化计算。但该矩阵的计算仍然需要耗费时间。表达式为`f(0) + [∂u/∂x,∂v/∂x]dx + dy[∂u/∂y,∂v/∂y]`  
```ruby
vec2 dX = dFdx(uv); # 硬件差分机制，获取附近像素中该值uv的差异差分 ∂uv/∂x
vec2 dY = dFdy(uv);
```

再根据导数大小进行平滑淡出可能是一个不错的选择。
