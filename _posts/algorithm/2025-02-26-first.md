## 参数地形相交
由于无法直接求解射线与复杂地形函数的代数交点，采用离散步进法。沿射线向前采样高度，并保留上一步的物理状态（地表高度lh和射线高度ly）。
一旦当前采样点钻入地下（p.y < h），说明射线在“上一步”到“这一步”之间穿过了地表。此时利用相似三角形进行线性插值，在最后一步的dt区间内精确截获交点，从而彻底消除表面断层和锯齿。  
实践中通常允许根据视线距离降低步进**精度**，因为远处的曲面像素细节很少，因此我们可以允许相关误差，这可以节省大量渲染时间。  
```cpp
float terra_marching( in vec3 ro, in vec3 rd) {
  float dt = 0.03, lh = 0.0, ly = 0.0;
  for (float t = 0.03; t < 50.0; t += dt) {
    vec3 p = ro + rd * t;
    float h = terra_map(p.x, p.z);
    if (p.y < h) return t - dt + dt * (lh - ly) / (p.y - ly - h + lh); // 两点插值
    dt = 0.03 + 0.01 * t;
    lh = h;
    ly = p.y;
  }
  return INF;
}
```
[《Raymarching terrains》,Inigo Quilez](https://iquilezles.org/articles/terrainmarching/)；

## Raymarching穿透SDF
普通光线行进不穿过SDF内部。  
①第一个问题是距离场在内部原本是负值，此时必须设为绝对值。但SDF必须正确实现内部距离。  
②表面吸附现象。当光线停靠表面太近时，重复发现过小的SDF值会导致重复的交点判定。如果被吸附了，必须丢弃当前的表面并沿续到下一个表面。  
③最后一个情况发生在介电内部还存在其他物体时，SDF将拒绝所有> 0的对象，应该使SDF只返回`[0, INF]`。  
```cpp
float marching( in vec3 ro, in vec3 rd) {
  float t = 0.0;
  bool adsorbed = abs(sdf(ro, id)) < .001;

  for (int i = 0; i < 50; ++i) {
    vec3 p = ro + t * rd;
    float dmin = abs(sdf(p, id));
    if (adsorbed && dmin > .001) adsorbed = false;

    if (!adsorbed && dmin < .001) return t;
    if (t > 100.) break;
    t += dmin;
  }
  return INF;
}
```
如果有问题。建议检查交点痤疮问题。
