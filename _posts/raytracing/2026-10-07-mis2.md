## 光子(Photons)
```ruby
E   # 能量，J
p   # 位置
D   # 传播方向
λ   # 波长 —— 两个相邻的峰之间的物理距离，nm
c   # 速度

h = 6.63 * 10^-34 Js #Plank’s Constant
E = hc/λ
```

## 方向功率
```ruby
Φ   # 功率，W=J/s
I   # 辐射强度(radiant intensity) —— dω上的功率
dΦ/dω
```

## 表面接受功率
```ruby
E(p)#辐照度(irradiance)
= dΦi/dA
```
表面接受的功率。i表示进。水面的焦散(Caustics)就是因为光线集中到特定位置形成。  

朗伯的余弦法通过辐照度进行解释，平行线代表固定功率，斜表面的能量被稀释。对比之下，斜线的照度就是E' = cosθE_A。

第二张图中，远处点光在dω发送的功率为dΦ = Idω。  
如果知道接受侧的几何参数，dA，r，θ，我们可以反向表达dω。  
如果，同心，那么dA归一就是dω，但是不是这样，乘以类似于上面的因子cosθ：dω= cosθ/r² dA。  
根据定义，接受侧的功率也等于EdA，无论如何，简单整理表达式，得到E = I cosθ/r²。  

这与图形学中的点光照明方程一致，说明功率会随着角度和距离变化！  

## 面方向功率
```ruby
L(p,ω) #辐射度(radiance)
= dI(p,ω)/dA    # 第一层功率来源是整块表面的特定出射方向功率(ω = 某个方向)
= d²Φ(p,ω)/dωdA # 二阶分子可以认为是被这两个划分后的剩余功率
```
一块小表面上有多少特定方向的方向功率。每块小表面都向四处反射功率。  

如果加上余弦修正为`LcosθdAdω`，因为从那块表面斜着发出去的光会被减弱。从这个式子来看，功率绝对减少了，否则无法解释平行根本不发出光。  
注意我们指的是功率，而事实是L本身保持不变，无论传播多远(在后面说明)。  

#### 计算面出辐照度
```ruby
M(p)#出辐照度(radiant exitance/radiosity)
= dΦo/dA
```
从表面辐出的功率，该反方向的量有很多术语，其符号还有Eo，B等。  

根据定义，代入辐射度的功率以及dA。意思是，只有辐射度一束光离开时，表面的整体出辐照度变化(仅该方向影响的量)。  
如果积分所有方向，我们可以得到其真实M。  
```ruby
dM(x,ω) = d²Φ(p,ω)/dA = Lo(p,ω)cosθdω # dM，以及M(x,ω)符号的出现，是因为我们需要表示M的一小部分
M = ∫H²|dM(x,ω) = ∫Lo(x,ω)cosθdω
```
即面光源(也可能是反射体)的表面发射功率。  

#### 均匀光源(反射体)
该性质称为漫反射，物理相当于令Lo(x,ω)等于常数。整理变为：  
```ruby
M = Lo∫H²|cosθdω
```

# PART2
关于余弦修正。我们之前提到的，在平行线、斜dA描述中是接收端修正。以及在辐射度发射的表面被修正。  
最后一个看起来不在表面上，但只是一种表达，本质上物理修正发生在表面(因为其表面发射)。  

## 场辐射度
如果出射辐射度与发射表面的法线**对齐**，则cos项无效，无需修正的辐射度称为场辐射度。  

该术语通常与测定光场有关，有许多相机设备可以测出各个完美对齐的场辐射度。使用这些数据可以无需计算直接渲染。  

## 辐射度的属性
**第一定律：辐射度守恒定律**。光线在传播过程中，沿该光线方向的辐射度保持不变。  

本质原因：如前所述，点光源的辐照度虽然会衰减。辐射度不会衰减。  
光线在虚空中散开，虽然你在对面用固定面积接收到的光子功率确实按1/r²减弱，但是，从你的眼睛看过去，源头那块发光面积在你的视野里，也刚好按1/r²的透视规律变小了！  
这就是光线追踪能够在计算机里反向运算的物理基石。  

在透镜中，照度被集中，但辐照度仍然有对比缩放，因此也不变。  

**第二定律：传感器（包括视网膜）响应光线的辐射度。**  
由于这个完美的正比例关系，图形学才将其映射为颜色值。  

## 环境中的辐照度
如果积分每条入射辐射度带来的dE，我们可以得到该小表面的辐照度。  
```ruby
Li(p,ω) = d²Φi(p,ω)/dωdA
dE(x,ω) = d²Φi(p,ω)/dA = Li(p,ω)cosθdω
E(x) = ∫H²|∫Li(x,ω)cosθdω
```

如果有一个均匀光源，命中特定表面区域Ω，我们可以计算其辐照度(直接光照)：  
```ruby
E(x) = ∫H²|L... = L∫Ω|cosθdω = LΩ~
```
该投影项再次出现，它是Ω下面的投影面积，乘以常数L即辐照度。  
类似的问题，可以用这个作类比。
