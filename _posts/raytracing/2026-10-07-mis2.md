## 光子(Photons)
```ruby
E   # 能量，J
p   # 位置
D   # 传播方向
λ   # 波长 —— 两个相邻的峰之间的物理距离，nm
c   # 速度

h = 6.63 * 10^-34 Js #Plank’s Constant
E = hc/λ
```

## 方向功率
```ruby
Φ   # 功率，W=J/s
I   # 辐射强度(radiant intensity) —— dω上的功率
dΦ/dω
```
例如，各向同性点光源的I强度都相等，总功率为Φ，Φ = ∫S²|Cdω = 4ΠC。I = Φ/4Π。  
认为将4Π上的一个点1/4Π分配Φ也是可以的。  

下面是聚光灯模型建模，其中θ为ω与主灯方向的夹角，s为系数。  
```ruby
I(ω) = Φcosθ^s [(s+1)/2Π]
```

## 辐照度
```ruby
E(p)#辐照度(irradiance)
= dΦi/dA
```
表面接受的功率。水面的焦散(Caustics)就是因为光线集中到特定位置形成。  

朗伯的余弦法通过辐照度进行解释，平行线代表固定功率，斜表面的能量被稀释。对比之下，斜线的照度就是cosθE-A。
