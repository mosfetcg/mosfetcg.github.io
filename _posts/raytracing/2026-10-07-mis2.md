数学要求：本文要求您对立体角(以及其微分元的形状)的理解。另外，积分往往必须展开立体角微元才能解析计算。  
大多数单位为速率值(即导数)，遵循微积分的所有性质。  

## 光子(Photons)
```ruby
E   # 能量，J
p   # 位置
D   # 传播方向
λ   # 波长 —— 两个相邻的峰之间的物理距离，nm
c   # 速度

h = 6.63 * 10^-34 Js #Plank’s Constant
E = hc/λ
```

## 方向功率
```ruby
Φ   # 功率，W=J/s
I   # 辐射强度(radiant intensity) —— dω上的功率
dΦ/dω
```
例如，各向同性点光源的I强度都相等，总功率为Φ，Φ = ∫S²|Cdω = 4ΠC。I = Φ/4Π。  
认为将4Π上的一个点1/4Π分配Φ也是可以的。  

下面是聚光灯模型建模，其中θ为ω与主灯方向的夹角，s为系数。  
```ruby
I(ω) = Φcosθ^s [(s+1)/2Π]
```

## 表面接受功率
```ruby
E(p)#辐照度(irradiance)
= dΦi/dA
```
表面接受的功率。水面的焦散(Caustics)就是因为光线集中到特定位置形成。  

朗伯的余弦法通过辐照度进行解释，平行线代表固定功率，斜表面的能量被稀释。对比之下，斜线的照度就是E' = cosθE_A。

第二张图中，远处点光在dω发送的功率为dΦ = Idω。  
如果知道接受侧的几何参数，dA，r，θ，我们可以反向表达dω。  
如果，同心，那么dA归一就是dω，但是不是这样，乘以类似于上面的因子cosθ：dω= cosθ/r² dA。  
根据定义，接受侧的功率也等于EdA，无论如何，简单整理表达式，得到E = I cosθ/r²。  

这与图形学中的点光照明方程一致，说明功率会随着角度和距离变化！  

## 面方向功率
```ruby
L(p,ω) #辐射度(radiance)
= dI(p,ω)/dA    # 第一个功率来源就是方向功率
= d²Φ(p,ω)/dωdA # 二阶分子可以认为是被这两个划分后的剩余功率
```
一块小表面上有多少特定方向的方向功率。每块小表面都向四处反射功率。  

如果加上余弦修正为`LoCosdAdω`，因为从那块表面斜着发出去的光会被减弱。从这个式子来看，功率绝对减少了，否则无法解释平行根本不发出光。  
注意我们指的是功率，而事实是L本身保持不变，无论传播多远。  

#### 计算光源出辐照度
```ruby
M(p)#出辐照度(radiant exitance/radiosity)
= dΦo/dA
```
反方向的量有很多术语，从表面辐出的功率，其符号还有Eo，B等。  

根据定义，代入辐射度的功率以及dA。这表明一束光离开时，表面的出辐照度变化(仅该方向的量)。  
如果积分所有方向，我们可以得到其真实M。  
```ruby
dM(x,ω) = d²Φ(p,ω)/dA = Lo(p,ω)cosθdω # dM，以及M(x,ω)符号的出现，只是因为确实只能表示其一部分
M = ∫H²|dM(x,ω) = ∫Lo(x,ω)cosθdω
```
即面光源的辐照度。  

#### 均匀光源
均匀漫反射发光体，其Lo(x,ω)等于常数。整理变为：  
其积分项的含义是立体角在下面的投影面积，上面就是斜线部分。无论如何，结果为Π。  
这种光源的出辐射度为M/Π。  
```ruby
M = Lo∫H²|cosθdω
```
