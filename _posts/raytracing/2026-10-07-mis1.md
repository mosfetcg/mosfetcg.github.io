## 采样
"采样……"就是指确定随机变量。  

#### 逆方法(inversion)
\_1 计算CDF。  
CDF只是PDF的累积函数，记为大P(x)=∫LEFTBOUND..x|fxdx。  
返回x之前的总概率。  

EXAMPLE: P(x) = ∫0..x xdx = 0.5x²

\_2 生成随机数ξ(等于CDF)，P(?) = ξ。就选择该样本。  
为了计算样本位置，解析CDF的逆函数——以便将ξ->x。  

EXAMPLE: IV(ξ)=sqrt(2ξ)

不解释其具体。  
该机制介绍了一维量遵循PDF的采样方法。可以自然推广到多个变量。  

#### 如何均匀采样圆上的点？
可以通过分步确定一个二维位置，并分别进行PDF。  

如果均匀，圆内一点的概率就是p(xy) = 100%/PI。矩形面积概率为p(xy)dxdy。  
我们让两个坐标系下的选择概率相等，但由于微元增加为rdrdθ(替换xy)，下面：
```ruby
p(r,θ)drdθ = p(xy)dxdy
p(r,θ)drdθ = p(xy)rdrdθ
    p(r,θ) = r/PI = p(r)p(θ)
```
由于可以独立选择两次，先解决θ，剩下的概率分配给r。  
```ruby
p(θ) = 100%/2PI  #=> P^-1 = 2PIξ1
p(r) = 2r            P^-1 = sqrt(ξ2)
```

实现该三角形的均匀采样，概率p(u,v) = 100% / 0.5 = 2。  

这里两个量是互相影响的，u确定时，v的可用范围会减小。(竖线范围内再决定采样)。  
我们按照下面的算法进行：  
```ruby
p(x)   = ∫p(x,y)dy   # 这是个正常二重积分的分步：将p(x,y)视为表达式，x视为常数。 称为边缘密度函数
p(y|x) = p(x,y)/p(x) # 称为条件密度函数

1. 计算p(x)
2. 抽取出X
3. 计算p(y|X)
4. 再次抽取Y
```
我们知道，当u确定时，v的范围就是0到1-u。继续根据公式2，可以得到：
```ruby
p(u) = ∫0..1-u|p(u,v)dv = 2(1-u)
p(v|u) = 1/(1-u)

P(u) = 2u-u², IV(ξ) = 1 - sqrt(1-ξ)
P(v) = ...#带u条件的v函数 
     = v/(1-u)
     
   ξ = v/(1-u)
IV(ξ) = ξ(1-u)
```
